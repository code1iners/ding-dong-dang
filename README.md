# 딩동댕

정해진 시각에 수업 종을 울리고, 종이 울리면 강아지가 나와서 알려 주는 학원용 데스크톱 앱이에요.

## 내려받기

- [Windows용 내려받기](https://github.com/code1iners/ding-dong-dang/releases/latest/download/DingDongDang-Setup.exe) (`DingDongDang-Setup.exe`)
- [Mac용 내려받기](https://github.com/code1iners/ding-dong-dang/releases/latest/download/DingDongDang.dmg) (`DingDongDang.dmg`, Apple Silicon Mac만 돼요)

이 앱은 개발자 서명을 받지 않아서 처음 설치할 때 컴퓨터가 경고를 보여 줘요. 아래 순서대로 하면 설치할 수 있어요.

> ⚠️ 이 안내의 경고 화면 문구는 실제 PC에서 확인하기 전에 쓴 부분이 있어요. 문구가 조금 다르게 보이면 화면의 같은 뜻의 단추를 고르세요. 실제 화면을 확인하면 이 안내를 고쳐요.

## Windows에 설치하기

<!-- 영상 자리 2/3 — Windows 설치 안내 영상(1분 안쪽). -->
> 🎬 Windows 설치 안내 영상은 준비 중이에요.

1. 위의 "Windows용 내려받기"를 눌러 `DingDongDang-Setup.exe`를 받아요.
2. 받은 파일을 두 번 눌러 실행해요.
3. 파란 화면에 "Windows의 PC 보호" 같은 경고가 뜨면 **추가 정보**를 눌러요.
4. 새로 나타난 **실행** 단추(영어 화면이면 "More info" → "Run anyway")를 눌러요.
5. 설치가 저절로 끝나고 딩동댕이 켜져요. 바탕 화면과 시작 메뉴에 바로가기도 생겨요. 관리자 권한은 필요 없어요.

새 버전을 사이트에서 다시 내려받아 설치할 때마다 이 경고가 또 나올 수 있어요. 앱 안의 업데이트는 이 경고를 거치지 않아요(아래 [업데이트](#업데이트) 참고).

### 차단 화면이 뜨면 (Smart App Control)

3~4번의 경고 화면에 **추가 정보**나 **실행** 단추가 없고 "이 앱은 차단되었습니다"처럼 막히기만 한다면 Windows의 Smart App Control이 켜져 있는 거예요. 서명이 없는 앱은 이 기능이 켜져 있으면 실행하지 못하게 막아요. 이 PC에서만 Smart App Control을 꺼야 설치할 수 있어요.

**켜져 있는지 확인하기**

1. 시작 메뉴에서 **Windows 보안**을 열어요.
2. 왼쪽의 **앱 및 브라우저 컨트롤**을 눌러요.
3. **스마트 앱 컨트롤 설정**을 눌러요. **켜기**로 되어 있으면 켜진 거예요. **끄기**로 되어 있거나 이 메뉴가 없으면 이 절은 건너뛰어도 돼요.

**끄기**

1. 위의 스마트 앱 컨트롤 설정 화면에서 **끄기**를 골라요.
2. 설치 파일을 다시 실행해서 위 순서대로 설치해요.

**끄면 생기는 영향**

- 서명이 없는 다른 앱도 이 PC에서 실행할 수 있게 돼요. 믿을 수 있는 파일만 실행하세요.
- Windows 버전에 따라 한 번 끄면 다시 켤 수 없어요. 다시 켜려면 Windows를 초기화해야 할 수 있으니, 끄기 전에 꼭 필요한지 생각해 보세요.
- 학원 PC라면 PC 관리자와 먼저 상의하세요.

## Mac에 설치하기

<!-- 영상 자리 3/3 — Mac 설치 안내 영상(1분 안쪽). -->
> 🎬 Mac 설치 안내 영상은 준비 중이에요.

Apple Silicon(M1 이후) Mac만 지원해요. Intel Mac에서는 설치할 수 없어요.

1. 위의 "Mac용 내려받기"를 눌러 `DingDongDang.dmg`를 받아요.
2. 받은 파일을 두 번 눌러 열고 **딩동댕**을 **응용 프로그램** 폴더로 끌어다 놓아요.
3. 응용 프로그램 폴더에서 **딩동댕**을 열어 봐요. "Apple은 '딩동댕'에 … 악성 코드가 없음을 확인할 수 없습니다"라는 창이 뜨면 **완료**를 눌러 닫아요.
4. **시스템 설정 > 개인정보 보호 및 보안**을 열고 아래로 내려가면 "'딩동댕'이(가) 차단되었습니다"라는 줄 옆에 **그래도 열기**가 있어요. 눌러요.
5. Mac 암호(또는 Touch ID)를 넣고 **열기**를 눌러요.

- **그래도 열기**는 3번에서 열기를 시도한 뒤 약 1시간 동안만 보여요. 안 보이면 3번부터 다시 하세요.
- 한 번 열고 나면 다음부터는 경고 없이 열려요.

## 업데이트

- 앱이 켜질 때와 그 뒤 24시간마다 새 버전이 있는지 저절로 확인하고, 있으면 조용히 받아 둬요.
- 받아 두면 왼쪽 **설정** 단추에 주황 점이 생겨요. 설정 화면 맨 아래 **버전** 줄에서 **업데이트**를 누르고 확인하면 설치하고 다시 켜져요. 눌러야만 설치돼요.
- 다음 종까지 2분이 안 남았거나 종이 울리는 중에는 **업데이트**를 누를 수 없어요. 종이 울린 뒤에 하세요.
- 앱 안의 업데이트는 Windows의 경고나 Mac의 **그래도 열기**를 다시 거치지 않아요. 사이트에서 새로 내려받아 설치할 때만 거쳐요.
- 인터넷이 안 되면 아무것도 보이지 않고, 설정 화면의 버전 줄에만 "새 버전을 확인할 수 없어요"와 **다시 확인**이 보여요.

## 그 밖의 안내

### 자동 시작 수동 등록 방법

딩동댕은 처음 켤 때 컴퓨터를 켜면 자동으로 시작되게 등록해요. 설정 화면의 **컴퓨터를 켜면 자동 시작**에 "등록하지 못했어요"가 보이면 아래 방법으로 직접 등록하세요.

**Windows**

1. 키보드의 Windows 키 + R을 누르고 `shell:startup`을 입력해 Enter를 눌러요. 시작 프로그램 폴더가 열려요.
2. 시작 메뉴 또는 바탕 화면의 **딩동댕** 바로가기를 이 폴더로 Ctrl을 누른 채 끌어다 놓아요(복사돼요).
3. 설정의 **컴퓨터를 켜면 자동 시작**은 끈 채로 둬도 돼요. 다음에 컴퓨터를 켜면 딩동댕이 시작돼요.

작업 관리자의 **시작 앱**에서 딩동댕이 "사용 안 함"으로 되어 있어도 등록되지 않은 거예요. **사용**으로 바꾸세요.

**Mac**

1. **시스템 설정 > 일반 > 로그인 항목**을 열어요.
2. **로그인 시 열기** 목록에 **딩동댕**이 없으면 아래의 **+** 를 누르고 응용 프로그램 폴더에서 **딩동댕**을 골라요.
3. 목록에 있는데 꺼져 있으면 스위치를 켜요.

### 데이터 폴더 위치와 옮기기

시간표, 등록한 종소리, 설정은 아래 폴더에 저장돼요.

- Windows: `%APPDATA%\ding-dong-dang` (파일 탐색기 주소창에 붙여 넣으면 열려요)
- Mac: `~/Library/Application Support/ding-dong-dang` (Finder에서 **이동 > 폴더로 이동**에 붙여 넣으면 열려요)

**데이터 폴더를 통째로 복사하면 옮겨져요.** 딩동댕을 완전히 종료한 뒤 폴더를 다른 PC의 같은 위치에 복사하고 딩동댕을 켜세요.

데이터를 지우려면 설정 화면의 **모든 데이터 지우기**를 쓰세요. Windows에서 앱을 제거할 때도 "저장한 시간표와 종소리도 지울까요?"라고 물어요.

### 종이 울리는 조건

- **덮개를 닫으면 종이 울리지 않아요.** 노트북은 덮개를 열어 둔 채로 쓰세요. 수업 시간에는 PC가 잠들지 않게 막지만, 덮개를 닫아 잠든 PC는 종을 울리지 못해요.
- **종이 안 들리면 PC 음량과 스피커 전원을 확인하세요.** 앱이 아니라 PC의 음소거나 스피커 전원이 꺼진 경우가 많아요.
- 놓친 종은 나중에 알려 주지 않아요.

### 여러 날 쉴 때

창의 닫기 버튼은 앱을 끄지 않고 숨기기만 해서 종은 계속 울려요. 방학처럼 여러 날 쉴 때는 아래처럼 끄세요.

1. 설정 화면의 **컴퓨터를 켜면 자동 시작**을 꺼요.
2. 작업 표시줄 오른쪽 아래(Windows) 또는 화면 위쪽 메뉴 막대(Mac)의 딩동댕 아이콘을 눌러 **딩동댕 종료**를 골라요. Mac에서는 Cmd+Q로도 종료돼요.

다시 쓸 때는 딩동댕을 직접 켜고 자동 시작을 다시 켜세요.

## 개발자용

Electron, React, TypeScript로 만들었어요. Node.js와 npm이 필요해요.

```sh
npm install        # 의존성 설치
npm run dev        # 개발 실행
npm run check      # 타입 검사, 린트, 단위 시험, e2e 시험
npm run dist       # Windows 설치 파일과 Mac dmg · zip 만들기 (게시하지 않음)
npm run release    # 빌드, 자동 검사, 업데이트 안내 파일 서명, GitHub Releases 게시
```

- Windows 설치 파일은 Apple Silicon Mac에서 베타 NSIS 툴셋(`toolsets.nsis: "1.2.1"`)으로 만들어요.
- 앱 내 업데이트의 서명 방식은 [ADR 0001](docs/adr/0001-in-app-update-trust.md), 용어는 [GLOSSARY.md](GLOSSARY.md), 화면 규칙은 [DESIGN.md](DESIGN.md)에 있어요.
- 설정 화면의 "자동 시작 등록 방법" 링크는 이 문서의 "자동 시작 수동 등록 방법" 절(`src/main/auto-start.ts`의 `AUTO_START_HELP_URL`)을 가리켜요. 절 제목을 바꾸면 상수의 해시도 맞추세요.
