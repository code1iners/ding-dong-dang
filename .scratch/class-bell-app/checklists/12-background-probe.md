# 점검 목록: 측정용 앱(BellProbe)으로 상주 동작 실측

[서명 없는 최소 Electron 앱으로 상주 동작 실측](../issues/12-unsigned-app-measurement.md)에서 에이전트가 직접 할 수 없는 측정이다. 화면을 잠그거나 PC를 재우거나 로그아웃해야 하는 것, 그리고 Windows PC에서 하는 것이 여기에 있다.

BellProbe는 15초마다 "딩동" 두 음을 내고, 본 것을 전부 로그 파일에 적는다. 잠금 · 잠자기 · 깨어남 · 종 지연은 로그에 남으므로 **적을 것은 "소리가 들렸는가"와 화면에 보인 것뿐이다.** 단계마다 시작한 시각(시:분)을 함께 적어 두면 로그와 맞춰 볼 수 있다.

트레이(메뉴 막대) 아이콘을 누르면 메뉴가 나온다: 지금 종 울리기, 잠자기 방지 블로커, 로그인 시 자동 실행, 로그 폴더 열기, 종료.

## Windows 11 (개인 PC)

받기: `https://macbook-m5-pro.tail9db1f7.ts.net:8445/ding-dong-dang/BellProbe-win32-x64.zip` (tailnet 안에서만 열린다. 안 되면 Mac의 `prototypes/bell-probe/dist/BellProbe-win32-x64.zip`을 USB 등으로 옮긴다.)

1. 압축을 풀고 `BellProbe.exe`를 실행한다. 경고 창이 뜨면 문구를 적거나 화면을 찍어 둔다(설치 실측 티켓에서도 쓴다).
2. **트레이 아이콘 위치**: 주황색 사각형 아이콘이 작업 표시줄 오른쪽에 바로 보이는가, `^`(숨겨진 아이콘) 안에 들어가 있는가?
3. **숨긴 창 소리**: 창이 하나도 없는 상태에서 30초쯤 기다린다. 15초마다 딩동이 들리는가?
4. **화면 잠금**: `Win + L`로 잠그고 40초 둔다. 잠긴 동안 종이 들리는가?
5. **화면 꺼짐**: 설정 > 시스템 > 전원에서 화면 끄기를 1분으로 줄이고, 화면이 꺼진 뒤 40초를 더 둔다. 화면이 꺼진 뒤에도 종이 들리는가? 노트북이면 전원 연결 상태와 배터리 상태에서 한 번씩 한다.
6. **잠자기**: 시작 > 전원 > 절전으로 재우고 1분 뒤 깨운다. 깨운 직후 종이 몰아서 울리는가, 다음 종은 제때 울리는가?
7. **블로커**: 트레이 메뉴에서 "잠자기 방지 블로커"를 켜고 5번을 한 번 더 한다.
8. **자동 실행**: 트레이 메뉴에서 "로그인 시 자동 실행"을 켜고 PC를 다시 시작한다. 로그인 뒤 아무것도 누르지 않아도 트레이에 아이콘이 떠 있고 종이 울리는가? 작업 관리자 > 시작 앱에 BellProbe가 보이는가?
9. 끝나면 "로그인 시 자동 실행"을 끄고, "로그 폴더 열기"로 나온 `probe-log.jsonl`을 Mac으로 가져온 뒤 앱을 종료한다. 압축을 푼 폴더는 지워도 된다.

## macOS (이 Mac)

앱은 두 벌이다. 둘 다 `prototypes/bell-probe/dist/` 아래에 있다.

- `BellProbeRaw-darwin-arm64/BellProbeRaw.app`: 빌드 도구가 만든 그대로(링커가 붙인 서명뿐).
- `BellProbeAdhoc-darwin-arm64/BellProbeAdhoc.app`: ad-hoc 서명을 다시 한 것.

1. `BellProbeAdhoc.app`을 열어 둔다. 메뉴 막대에 "종"이라는 글자가 보인다.
2. **화면 잠금**: `Ctrl + Cmd + Q`로 잠그고 40초 둔다. 잠긴 동안 종이 들리는가?
3. **잠자기**: Apple 메뉴 > 잠자기로 재우고 1분 뒤 깨운다. 깨운 직후 종이 몰아서 울리는가, 다음 종은 제때 울리는가? (이 Mac은 다른 프로그램이 잠자기를 막고 있을 수 있다. 재워지지 않으면 덮개를 닫는다.)
4. **자동 실행**: 두 앱을 모두 열고 각각 메뉴에서 "로그인 시 자동 실행"을 켠다. 메뉴의 "상태"가 무엇으로 나오는지 적고, 로그아웃했다가 다시 로그인한다. 두 앱 중 어느 것이 저절로 떠 있는가? 시스템 설정 > 일반 > 로그인 항목에는 어떻게 보이는가?
5. 끝나면 두 앱 모두 "로그인 시 자동 실행"을 끄고 종료한다. 로그는 에이전트가 직접 읽으므로 옮길 필요가 없다(`~/Library/Application Support/BellProbe/probe-log.jsonl`).
