# 지도: 수업 종 데스크톱 앱 (딩동댕)

Label: wayfinder:map

## Destination

애견 미용 학원용 수업 종 데스크톱 앱(Windows 11 · macOS) v1 스펙을 쓰는 데 필요한 결정이 모두 잠긴 상태. 스펙 문서 작성과 구현은 지도가 끝난 뒤 사용자가 따로 요청한다.

## Notes

- 도메인: 시각 고정 **시간표**에 따라 **수업 시간**과 **쉬는 시간**의 경계에서 **종**을 울리는 단독 로컬 앱. 용어는 루트 `GLOSSARY.md`를 따른다.
- 이미 정해진 전제 (charting 대화에서 사용자 확정):
  - 기술 스택은 Electron.
  - 계정 · 서버 · PC 간 동기화 없음. 한 대의 PC에 설치해 스피커로 소리를 낸다.
  - 소수 직접 배포. 서명 없는 설치 파일 + 안내문. 주 대상은 Windows 11이지만 macOS도 같은 수준으로 지원한다.
  - UI 언어는 한국어 전용.
  - v1 핵심: 시간표 편집 + 정해진 시각에 종 재생 + 백그라운드 상주(트레이/메뉴 막대).
  - 화면은 현황(지금 교시, 다음 종까지 남은 시간)과 시간표 편집 두 축.
  - 디자인: 강아지와 관련된 귀여운 디자인. 텍스트는 최소화하고 시각 요소 위주로 깔끔하게.
  - 강아지가 화면 바닥을 돌아다니는 연출을 넣고, 설정에서 켜고 끌 수 있게 한다.
  - Smart App Control 대응 UI가 필요하다(형태와 위치는 배포와 설치 방식 결정에서 정한다).
  - Windows 실측은 사용자의 개인 Windows PC에서 한다. 에이전트가 접근할 수 없으므로 점검 목록을 만들어 전달한다.
- 매 세션이 참고할 Skill: 그릴링 티켓은 `grilling` + `domain-modeling`, 시안 티켓은 `prototype` + `ui-design`, 조사 티켓은 `research`.
- 눈으로 봐야 판단할 수 있는 결정은 단독 HTML 시안으로 만들어 Tailscale 경로(`~/.claude-mukkebi/mockups/ding-dong-dang/`)로 전달한다.
- 조사 결과는 `research/<name>` 브랜치에 남기고 티켓에서 가리킨다.

## Decisions so far

<!-- 닫힌 티켓마다 한 줄: 요지 + 링크 -->

- [강아지 테마 귀여운 디자인 레퍼런스 조사](issues/03-design-references.md): 방향 후보 3개(말랑 스티커, 포근한 미용실, 픽셀 산책길)와 앱 내장 가능한 한글 둥근 글꼴 후보를 얻었다. 조사한 타이머 앱은 모두 숫자 시각을 하나는 남겼다.
- [Electron 상주와 시각 정확도의 OS별 한계 조사](issues/01-os-background-reliability.md): 스케줄러는 메인 프로세스, 소리는 숨긴 창에서 내야 한다. 잠든 PC에서는 종을 울릴 수 없고, macOS 자동 실행은 서명 없는 앱에서 실패할 위험이 크다. 실측이 필요한 항목이 남았다.
- [서명 없는 Electron 앱의 설치 경험과 빌드 방법 조사](issues/02-unsigned-distribution.md): Windows는 SmartScreen 경고를 넘기면 되지만 Smart App Control이 켜진 PC에서는 차단된다. macOS는 ad-hoc 서명과 시스템 설정의 Open Anyway 절차가 필요하다. Windows 형식의 기본 후보는 electron-builder NSIS다.
- [화면 바닥을 돌아다니는 강아지 연출의 구현 가능성 조사](issues/04-roaming-dog-feasibility.md): 창 안 방식은 걸리는 것이 없고, 화면 전체 오버레이는 가능하지만 OS별 열린 이슈가 있어 실측이 필요하다. 어느 방식이든 대부분 정지해 있는 행동 설계가 필요하고, 자산과 상태 기계는 두 방식이 공유할 수 있다.

## Not yet specified

- 종 음원의 출처와 라이선스: 종소리 정책이 정해져야 무엇을 구할지 알 수 있다.
- 화면 전체 오버레이 방식의 실기기 검증(정지 이미지 하나짜리 오버레이 프로토타입): 강아지 연출의 범위에서 오버레이를 고를 때만 필요하다.
- 강아지 캐릭터 · 일러스트 자산의 제작 방식(AI 생성, 무료 소재, 직접 준비)과 필요한 동작 목록: 시안 방향과 강아지 연출 범위가 정해진 뒤.
- 설정 화면에 들어갈 항목 전체: 각 정책 티켓이 설정 가능한 것을 내놓은 뒤 모인다.
- 현황 화면이 남은 시간과 현재 교시를 텍스트 없이 어떻게 보여 줄지의 세부: 시안 방향이 정해진 뒤.
- 시간표와 설정의 저장 방식, 백업 · 내보내기 필요 여부: 시간표 모델이 정해진 뒤.
- 시각에 의존하는 동작(종 울림, 잠자기 복귀)을 어떻게 자동 검증할지: 상주와 신뢰성 정책이 정해진 뒤.

## Out of scope

- 간격 타이머(시작 버튼을 누른 뒤 반복하는 뽀모도로 방식): v1은 시각 고정 시간표만 다룬다.
- 계정, 서버, 여러 PC 간 동기화: 단독 로컬 앱으로 확정.
- 스토어 등록, 코드 서명 · 공증, 자동 업데이트: 소수 직접 배포로 확정.
- 한국어 외 언어 지원.
- 교실 TV용 전체 화면 모드: 요청이 없었다.
- 스펙 문서 작성과 구현: 지도 완료 뒤 별도 요청.
