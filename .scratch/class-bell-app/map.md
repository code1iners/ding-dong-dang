# 지도: 수업 종 데스크톱 앱 (딩동댕)

Label: wayfinder:map

## Destination

애견 미용 학원용 수업 종 데스크톱 앱(Windows 11 · macOS) v1 스펙을 쓰는 데 필요한 결정이 모두 잠긴 상태. 스펙 문서 작성과 구현은 지도가 끝난 뒤 사용자가 따로 요청한다.

## Notes

- 도메인: 시각 고정 **시간표**에 따라 **수업 시간**과 **쉬는 시간**의 경계에서 **종**을 울리는 단독 로컬 앱. 용어는 루트 `GLOSSARY.md`를 따른다.
- 이미 정해진 전제 (charting 대화에서 사용자 확정):
  - 기술 스택은 Electron.
  - 계정 · 서버 · PC 간 동기화 없음. 한 대의 PC에 설치해 스피커로 소리를 낸다.
  - 소수 직접 배포. 서명 없는 설치 파일 + 설치 안내. 주 대상은 Windows 11이지만 macOS도 같은 수준으로 지원한다.
  - UI 언어는 한국어 전용.
  - v1 핵심: 시간표 편집 + 정해진 시각에 종 재생 + 백그라운드 상주(트레이/메뉴 막대).
  - 화면은 현황(지금 교시, 다음 종까지 남은 시간)과 시간표 편집 두 축.
  - 디자인: 강아지와 관련된 귀여운 디자인. 텍스트는 최소화하고 시각 요소 위주로 깔끔하게.
  - 강아지가 화면 바닥을 돌아다니는 연출을 넣고, 설정에서 켜고 끌 수 있게 한다. 종이 울리는 동안 뜨는 강아지는 이 설정과 무관하다.
  - Smart App Control 대응 UI가 필요하다(형태와 위치는 배포와 설치 방식 결정에서 정한다).
  - 사용자가 손으로 해야 하는 실기기 확인(Windows PC 전체, 화면 잠금 · 잠자기 · 로그아웃이 필요한 것)은 지도에서 하지 않고 구현을 마친 뒤 수동 통합 테스트에서 한다. 그 전의 결정은 나쁜 쪽을 가정하고 내린다. 넘긴 항목은 `checklists/post-implementation.md`에 모은다.
- 매 세션이 참고할 Skill: 그릴링 티켓은 `grilling` + `domain-modeling`, 시안 티켓은 `prototype` + `ui-design`, 조사 티켓은 `research`.
- 티켓의 검증은 에이전트가 직접 하는 것만 둔다. 시안을 보고 듣고 고르는 것은 검증이 아니라 사용자의 결정이므로 티켓에 남는다.
- 눈으로 봐야 판단할 수 있는 결정은 단독 HTML 시안으로 만들어 Tailscale 경로(`~/.claude-mukkebi/mockups/ding-dong-dang/`)로 전달한다.
- 조사 결과는 `research/<name>` 브랜치에 남기고 티켓에서 가리킨다.

## Decisions so far

<!-- 닫힌 티켓마다 한 줄: 요지 + 링크 -->

- [강아지 테마 귀여운 디자인 레퍼런스 조사](issues/03-design-references.md): 방향 후보 3개(말랑 스티커, 포근한 미용실, 픽셀 산책길)와 앱 내장 가능한 한글 둥근 글꼴 후보를 얻었다. 조사한 타이머 앱은 모두 숫자 시각을 하나는 남겼다.
- [Electron 상주와 시각 정확도의 OS별 한계 조사](issues/01-os-background-reliability.md): 스케줄러는 메인 프로세스, 소리는 숨긴 창에서 내야 한다. 잠든 PC에서는 종을 울릴 수 없고, macOS 자동 실행은 서명 없는 앱에서 실패할 위험이 크다. 실측이 필요한 항목이 남았다.
- [서명 없는 Electron 앱의 설치 경험과 빌드 방법 조사](issues/02-unsigned-distribution.md): Windows는 SmartScreen 경고를 넘기면 되지만 Smart App Control이 켜진 PC에서는 차단된다. macOS는 ad-hoc 서명과 시스템 설정의 Open Anyway 절차가 필요하다. Windows 형식의 기본 후보는 electron-builder NSIS다.
- [화면 바닥을 돌아다니는 강아지 연출의 구현 가능성 조사](issues/04-roaming-dog-feasibility.md): 창 안 방식은 걸리는 것이 없고, 화면 전체 오버레이는 가능하지만 OS별 열린 이슈가 있어 실측이 필요하다. 어느 방식이든 대부분 정지해 있는 행동 설계가 필요하고, 자산과 상태 기계는 두 방식이 공유할 수 있다.
- [시간표 모델 결정](issues/05-timetable-model.md): 이름 붙인 시간표 여러 개를 요일마다 하나씩 배정하고 바꿀 때까지 매주 반복한다. 수업 시간만 입력하며 날짜별 예외는 없고, 오늘만 끄기 스위치 하나로 쉰다(전체 끄기는 뒤에 뺐다).
- [앱 아이콘 레퍼런스와 규격 조사](issues/18-app-icon-references.md): 아이콘 방향 후보 4개(얼굴 한가득, 귀 달린 종, 방울 목걸이, 픽셀 멍종)와 Windows · macOS 규격을 얻었다. 트레이 · 메뉴 막대 아이콘은 별도의 단색 기호로 따로 그려야 한다.
- [종소리 레퍼런스와 음원 출처 조사](issues/15-bell-sound-references.md): 후보 묶음 5개(학교 차임, 딩동댕, 실로폰 · 오르골, 핸드벨, 강아지 테마)와 바로 내장할 수 있는 CC0 음원을 얻었다. 드라이기 소음에는 어떤 종이든 묻힐 수 있고 고주파 단속음은 강아지를 자극한다.
- [종소리 정책 결정](issues/06-bell-policy.md): 시작종과 끝종을 구분하고 예비종은 없다. 내장 음원과 1분 이하의 등록 음원 중에서 각각 고르며 음량은 음원별 × 전체다. 종이 울리는 동안 화면에 강아지 창이 뜨고 누르면 종이 멈춘다.
- [한국 중 · 고등학교 수업 종 음원 조사](issues/20-korean-school-bell-sounds.md): 학교 종은 방송 타이머의 내장 멜로디(소녀의 기도, 엘리제를 위하여, 웨스트민스터 등 11곡)이고 들어 볼 링크를 얻었다. 기기에서 나온 음원은 내장할 수 없어 등록 음원으로만 쓸 수 있고, 멜로디를 직접 합성하면 내장할 수 있다.
- [무료 강아지 일러스트 소재 조사](issues/21-dog-illustration-sources.md): 표정 · 자세가 한 캐릭터로 모두 묶인 외곽선 없는 무료 소재는 없다. Noto Emoji(Apache-2.0)와 Openclipart(CC0)가 그림체와 라이선스에서 가장 쓸 만하고, 졸림과 걷기는 어느 쪽이든 따로 그려야 한다.
- [Unsplash 강아지 일러스트 세트 추가 조사](issues/22-unsplash-dog-illustration-sets.md): 표정과 자세를 한 캐릭터로 다 갖춘 무료 묶음은 없다. 무료 일러스트는 SVG 원본을 받아 고쳐 쓸 수 있고, 그림체가 맞는 것은 The Creative Idea의 강아지 1점과 Public domain vectors의 플랫 8점이다.
- [디자인 시안 비교와 방향 선택](issues/08-design-mockups.md): 말랑 스티커 방향에 글꼴은 Jua. 현황 화면은 줄어드는 고리, 시간표 편집 화면은 12시간 시계판과 요일 선택이다. 강아지는 테마 일곱 개를 설정에서 고르고, 그림 한 장에 코드로 부위별 움직임을 붙인다.
- [서명 없는 최소 Electron 앱으로 상주 동작 실측](issues/12-unsigned-app-measurement.md): Mac에서 로그인 항목 등록은 성공으로 나오고, 숨긴 창 오디오는 재생되며, 창 없는 앱의 타이머는 늦지 않았다. 화면 잠금 · 잠자기 · Windows 동작은 미확인으로 남기고 구현 뒤 확인한다.
- [학원 PC의 Smart App Control 상태 확인](issues/13-academy-pc-sac-check.md): 확인하지 않고 구현 뒤로 넘겼다. Smart App Control이 켜져 있을 수 있고 수업 중 화면이 꺼지거나 잠자기에 들어갈 수 있다고 가정하고 결정한다.
- [상주와 신뢰성 정책 결정](issues/07-background-reliability-policy.md): 자동 실행은 기본 켬이고 닫기 버튼은 트레이로 숨긴다. 수업 구간에는 잠자기를 막고, 1분 넘게 늦은 종은 버리며 놓친 종은 알리지 않는다. 음소거 경고는 넣지 않는다.
- [서명 없는 빌드 산출물의 설치 실측](issues/14-unsigned-build-install-measurement.md): Apple Silicon에서 NSIS 설치 파일은 기본 툴셋으로는 실패하고 베타 NSIS 툴셋을 지정하면 Wine 없이 만들어진다. ad-hoc 서명 Mac 빌드는 격리 상태에서 "손상됨"이 아닌 "확인할 수 없음" 경고를 받는다. Open Anyway로 여는 확인은 구현 뒤로 넘겼다.
- [서명 없는 앱의 앱 내 업데이트 가능성 조사](issues/25-unsigned-in-app-update.md): Windows는 서명 없이도 electron-updater로 내려받아 설치하고 다시 실행할 수 있다(실기기 미확인). macOS는 기본 ad-hoc 서명으로는 자동 설치가 안 되고, 앱이 dmg를 내려받아 열어 주는 방식이 안전하다. GitHub Releases는 공개 저장소여야 하고 최신 파일을 가리키는 고정 주소를 쓸 수 있다.
- [내려받기 페이지 레퍼런스와 제공 경로 조사](issues/26-download-page-references.md): 경로 후보 넷 중 추천은 학원 사이트의 `/app/`이고, 노출은 경로 이름이 아니라 메뉴 링크와 `noindex`로 정해진다. 버튼은 GitHub Releases의 고정 주소를 평범한 링크로 가리킨다. 학원 사이트는 별도 저장소이고 새 페이지를 더할 때의 제약(빌드 플러그인, 테스트, 파일 25 MiB 한도)을 얻었다.
- [배포와 설치 방식 결정](issues/11-distribution-decision.md): Windows는 NSIS 원클릭 설치, Mac은 Apple Silicon 전용 dmg이고 개발 Mac에서 명령 하나로 공개 GitHub 저장소에 릴리스한다. 학원 사이트의 "앱 다운로드" 영역에서 내려받고 설치 안내는 README의 영상과 글 절차로 한다. 설정 화면에서 확인 모달을 거쳐 업데이트하고 다시 실행하며 업데이트 진위는 Ed25519로 검증한다.
- [종소리 청취 시안과 음원 확정](issues/16-bell-sound-selection.md): 내장 음원은 직접 합성한 여섯 짝이고 음색은 부드러운 차임이다. 기본값은 웨스트민스터 차임(시작종 앞 2소절, 끝종 뒤 2소절)이다. 파일 음원 후보는 모두 쓰지 않아 출처 표기가 필요 없다.
- [저장 방식과 백업 결정](issues/17-storage-and-backup.md): 사용자 데이터 폴더의 JSON 파일 하나와 `sounds/` 폴더에 저장하고, 예비본과 형태 버전으로 깨진 파일 · 형태 변경에 대비한다. 앱을 지워도 데이터는 남고 Windows 제거 때의 질문과 설정 화면의 "모든 데이터 지우기"로 전부 지울 수 있다. 음소거 전용 설정은 두지 않는다.
- [앱 아이콘 시안 비교와 확정](issues/19-app-icon-selection.md): 앱 아이콘은 주황 바탕의 발바닥 종이고 Windows는 둥근 타일로 따로 만든다. 트레이 · 메뉴 막대는 같은 실루엣이며 오늘만 끄기는 빗금으로 구분한다. Windows 트레이는 색 아이콘 하나를 쓰고 꺼지면 회색에 빗금이다. 원본은 직접 그린 SVG다.
- [강아지 테마 SVG의 부위 구성 확인](issues/23-dog-theme-svg-parts.md): 여섯 테마 모두 귀와 눈이 따로 그려져 있어 뺄 테마가 없다. 얼굴 테마는 꼬리가, 두 테마는 혀가 없어 신남을 만드는 부위가 테마마다 다르다. 걷는 다리를 만들 수 있는 것은 뻐드렁니 강아지와 코드로 그린 강아지뿐이다.
- [걷는 모션을 만들 수 있는 강아지 그림 소재 추가 조사](issues/27-walkable-dog-art-sources.md): 네 다리가 따로 그려진 무료 옆모습 그림을 7점 찾았다(코기, 바셋 하운드 둘, 회색 얼룩 강아지 등, 모두 CC0 또는 퍼블릭 도메인). 걷는 모션이 이미 들어 있는 플랫 소재도 9점 있으나 대부분 Lottie다.
- [강아지 연출의 범위와 동작 결정](issues/09-roaming-dog-behavior.md): 돌아다니는 강아지는 앱 창이 아니라 주 모니터의 화면 바닥에 있고, 수업 시간에 돌아다니며 그 밖에는 제자리에서 쉰다. 누르면 하트가 나오고 끌어 놓으면 낙하산으로 내려오며, 종이 울릴 때는 이 강아지를 눌러 멈춘다. 걷는 테마는 둘이고 나머지는 통통 튀며, 크기는 설정의 슬라이더로 바꾼다.
- [시각에 의존하는 동작의 자동 검증 방법 결정](issues/24-time-dependent-verification.md): 종 판정은 시각을 값으로 받는 순수 함수이고 스케줄러는 1초마다 지난번 확인 이후를 묻는다. 시각이 뒤로 가거나 앱이 막 켜졌을 때는 지난 종을 울리지 않고, 오늘만 끄기는 끈 날짜로 저장한다. 스펙에 시나리오 표를 넣고 실제 앱 확인 하나는 에이전트가 한다.
- [돌아다니는 강아지 창을 Mac에서 검증하기](issues/28-roaming-dog-window-verification.md): 강아지보다 조금 큰 투명 창 하나를 움직이는 방식으로 만든다. 걸을 때 초당 24번, 멈춰 쉴 때 초당 4번 그려 10분 평균이 한 코어의 4.2%였다. Mac에서 강아지를 누르면 딩동댕이 맨 앞 앱이 되는 것은 감수하고, 화면 잠금 · Windows 확인은 구현 뒤로 넘겼다.

## Not yet specified

- 설정 화면에 들어갈 항목 전체: 각 정책 티켓이 설정 가능한 것을 내놓은 뒤 모인다. 지금까지 나온 것은 강아지 테마 고르기, 돌아다니는 강아지 켜기 · 끄기, 돌아다니는 강아지 크기, 로그인 시 자동 실행, 닫기 버튼으로 트레이에 숨기기, 수업 중 화면 켜 두기, 버전과 업데이트, 모든 데이터 지우기다.

## Out of scope

- 간격 타이머(시작 버튼을 누른 뒤 반복하는 뽀모도로 방식): v1은 시각 고정 시간표만 다룬다.
- 계정, 서버, 여러 PC 간 동기화: 단독 로컬 앱으로 확정.
- 스토어 등록, 코드 서명 · 공증: 소수 직접 배포로 확정. 승인 없이 저절로 설치하는 업데이트도 두지 않는다(설정 화면에서 승인하는 앱 내 업데이트는 범위 안이다).
- 소개 영상과 설치 안내 영상의 스토리보드 · 제작: 완성된 앱 화면과 실제 경고 화면이 필요해 구현과 수동 통합 테스트 뒤의 별도 작업으로 한다. 요건만 [배포와 설치 방식 결정](issues/11-distribution-decision.md)에 잠갔다.
- 학원 사이트의 "앱 다운로드" 영역 시안 · 제작: 학원 사이트 저장소의 별도 작업이다. 이 앱의 스펙은 카드가 가리킬 주소만 정한다([배포와 설치 방식 결정](issues/11-distribution-decision.md)).
- 내보내기 · 가져오기: PC를 바꾸면 다시 입력한다. README에 데이터 폴더를 복사하는 방법만 적는다([저장 방식과 백업 결정](issues/17-storage-and-backup.md)).
- 소리만 끄는 음소거 설정: 전체 음량을 0으로 내리는 것으로 대신한다([저장 방식과 백업 결정](issues/17-storage-and-backup.md)).

- 공휴일 달력, 날짜별 예외, 특정 날짜에만 다른 시간표 쓰기: 요일 배정을 직접 바꾸는 것으로 대신한다([시간표 모델 결정](issues/05-timetable-model.md)).
- 교실 TV용 전체 화면 모드: 요청이 없었다.
