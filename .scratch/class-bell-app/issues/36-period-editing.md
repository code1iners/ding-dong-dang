# 36: 수업 시간 편집과 저장

**What to build:** 시간표의 수업 시간을 더하고, 고치고, 지우고, 12시간 시계판에서 호로 본다. 잘못된 시각은 그 줄에 표시되고 저장이 막힌다. [스펙](../spec.md)의 "시간표와 요일 배정", "화면"과 `DESIGN.md`의 "시간표" 화면 규칙을 따른다.

Blocked by: 32, 35

Status: ready-for-agent

- [ ] 오른쪽 카드에 교시별 시작 · 끝 시각 줄과 "수업 시간" 더하기가 있다. 교시 번호는 시작 시각 순서로 매겨진다. 시각의 숫자는 자리마다 같은 폭의 칸에 들어간다.
- [ ] 왼쪽 카드의 12시간 시계판에 수업 시간이 교시 번호가 붙은 호로 나온다.
- [ ] 수업 시간을 더하거나 고치거나 지우면 "되돌리기"와 "저장"이 나타난다. "되돌리기"는 마지막 저장 상태로 돌린다.
- [ ] 검증 오류가 있으면 그 줄에 빨간 테두리, 아래에 느낌표와 이유 한 줄이 보이고 "저장"이 잠긴다. 자동으로 고치지 않는다.
- [ ] 저장하지 않은 채 다른 화면, 다른 요일, 다른 시간표로 가거나 창을 닫으려 하면 "계속 편집", "저장 안 함", "저장" 모달이 뜬다. 오류가 있으면 모달의 "저장"도 잠긴다.
- [ ] "저장"이 실패하면 편집 상태가 그대로 남고 그 자리에서 실패 알림이 뜬다.
- [ ] 한 시간표를 저장하면 그 시간표를 쓰는 모든 요일이 함께 바뀐다.
- [ ] 실제 앱 테스트: 수업 시간을 더해 저장하고 앱을 다시 띄우면 남아 있다. 겹치는 수업 시간에서 "저장"이 잠긴다. 저장하지 않고 다른 화면으로 가면 모달이 뜬다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
