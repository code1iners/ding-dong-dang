# 32: 종 판정과 시간표 검증

**What to build:** 종을 울릴지, 지금이 어떤 상태인지, 잠자기를 막아야 하는지를 시각을 값으로 받아 정하는 순수 함수와, 시간표의 잘못된 수업 시간을 줄별로 찾아내는 순수 함수. [스펙](../spec.md)의 "종 판정 규칙", "현황 계산", "시간표와 요일 배정"의 검증 규칙을 따른다.

Blocked by: 30

Status: ready-for-agent

- [ ] 종 판정 함수는 시계, 타이머, Electron을 모른다. 입력은 시간표 목록, 요일 배정, 끈 날짜, 지난번 확인 시각, 지금 시각이고 출력은 울릴 종, 현황, 잠자기를 막아야 하는지다.
- [ ] 스펙 "Testing Decisions"의 시나리오 표 22줄이 모두 테스트로 있고 통과한다.
- [ ] 현황이 여섯 상태 중 하나와 지금 교시 번호, 오늘의 교시 수, 다음 종의 종류와 시각, 지금 구간의 시작과 끝을 낸다. 여섯 상태마다 테스트가 있다.
- [ ] 시간표 검증 함수가 규칙마다(끝이 시작보다 늦음, 겹침 없음, 첫 시작부터 마지막 끝까지 12시간 이하) 통과와 실패를 줄 번호와 이유로 돌려준다. 끝과 시작이 같은 경우와 정확히 12시간인 경우는 통과한다.
- [ ] 수업 시간이 없는 시간표는 검증을 통과하고, 그 요일의 판정은 "수업 없는 날"이다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
