# 시각에 의존하는 동작의 자동 검증 방법 결정

Type: grilling
Status: resolved
Blocked by: 

## Question

에이전트가 실제 시각을 기다리지 않고 다음 동작을 자동으로 검증하려면 스펙에 어떤 구조와 테스트 방식을 요구해야 하는가?

- 종 시각에 종이 울리는 것, 같은 시각의 끝종 · 시작종 중 시작종만 울리는 것.
- 늦은 종 규칙(1분 이내만 울리고 밀린 것 중 최근 하나만 따진다)과 깨어난 직후의 동작.
- 시스템 시각 변경, 자정 넘김(오늘만 끄기 해제, 요일 배정 전환).
- 수업 구간 동안의 잠자기 막기 시작 · 해제.

정책은 [상주와 신뢰성 정책 결정](07-background-reliability-policy.md), [종소리 정책 결정](06-bell-policy.md), [시간표 모델 결정](05-timetable-model.md)에 있다. 사람이 하는 실기기 확인은 `checklists/post-implementation.md`에 따로 있다.

## Answer

그릴링 대화에서 사용자가 확정한 내용이다(2026-11-17).

구조:

- 종을 울릴지 정하는 판정은 시계 · 타이머 · Electron을 모르는 순수 함수로 둔다. 입력은 시간표, 요일 배정, 오늘만 끄기 상태, 지난번 확인 시각, 지금 시각이고, 출력은 울릴 종(없음 / 시작종 / 끝종), 지금 교시, 잠자기를 막아야 하는지다.
- 스케줄러는 다음 종에 맞춘 타이머를 걸지 않고 1초마다 깨어나 "지난번 확인 시각부터 지금까지 사이에 종이 있었나"를 판정 함수에 묻는다. PC가 잠에서 깨어난 때에도 바로 한 번 묻는다. 잠자기에서 깨어남, 앱 멈춤, 시스템 시각 변경은 모두 "지난번과 지금 사이가 벌어졌다"는 한 경우로 처리한다. 종은 최대 1초 늦을 수 있다.
- 스케줄러는 시계, 1초 타이머, 깨어남 신호, 소리 재생, 잠자기 막기를 갈아 끼울 수 있는 부품으로 받는다.

이 티켓에서 메운 정책:

- 시스템 시각이 뒤로 가면 그 순간에는 아무 종도 울리지 않는다. 새 시각 기준으로 종 시각이 다시 오면 한 번 더 울린다. 이미 울린 종은 따로 기억하지 않는다. 앞으로 건너뛴 경우는 늦은 종 규칙 그대로다.
- 앱이 막 시작된 순간에는 방금 지난 종이 있어도 울리지 않고 시작 시각 이후의 종부터 울린다. 늦은 종 규칙은 앱이 켜져 있었는데 PC가 잠들었거나 멈췄던 경우에만 적용한다.
- 오늘만 끄기는 "끈 날짜"로 저장하고 그 날짜가 PC 현지 시각의 오늘과 같을 때만 꺼진 것으로 본다. 자정에 푸는 타이머는 없다. 요일 배정 전환도 지금 시각의 요일만 보고 정한다.

검증 방식:

- 판정 함수는 시각을 값으로 넣는 테스트로 검증한다. 스케줄러는 가짜 부품을 끼워 시각을 즉시 넘기고 "시작종 재생을 요청했다", "잠자기 막기를 시작 / 해제했다"가 기록됐는지로 검증한다.
- 실제 앱을 띄워 실제 시각으로 종 하나를 확인하는 검증을 하나 둔다. 임시 데이터 폴더에 몇 초 뒤에 시작하는 수업 시간이 든 시간표를 써 넣고 앱을 띄워, 숨긴 창에서 재생이 시작되고 강아지 창이 뜨는 것을 확인한다. 이 확인은 에이전트 검증으로만 하고 사람의 확인 항목으로 두지 않는다. 이를 위해 앱은 데이터 폴더 위치를 실행 인자로 바꿀 수 있어야 한다. 제품 코드에 시각을 속이는 장치는 넣지 않는다.
- 스피커에서 실제로 소리가 나는지는 자동 검증하지 않는다. `checklists/post-implementation.md`의 수동 통합 테스트에 이미 있다.

스펙에 넣을 시나리오 표(입력 → 기대 결과). 구현 티켓의 완료 조건이 이 표의 통과를 가리킨다. 구체적인 시각 값과 테스트 도구는 스펙을 쓸 때 정한다.

- 종 시각의 시작종 · 끝종, 같은 시각이면 시작종만.
- 늦은 종: 59초 늦음(울림), 61초 늦음(버림), 여러 개 밀림(가장 최근 것만 따짐).
- 시각이 뒤로 감(울리지 않음, 다시 그 시각이 되면 울림), 앱 시작 직후(울리지 않음).
- 자정 넘김: 오늘만 끄기 풀림, 요일 배정 전환, 배정 없는 요일.
- 오늘만 끄기 중과 다시 켠 직후, 오늘 시간표를 고친 직후(지난 종은 울리지 않음).
- 잠자기 막기: 첫 수업 시작에 켜짐, 마지막 수업 끝에 꺼짐, 오늘만 끄기 · 배정 없는 요일에는 꺼짐.

글로서리는 바꾸지 않았다. ADR도 만들지 않았다(되돌리기 어렵지 않다).
