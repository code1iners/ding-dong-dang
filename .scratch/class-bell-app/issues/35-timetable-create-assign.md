# 35: 시간표 만들기와 요일 배정

**What to build:** 시간표 화면에서 시간표를 만들고, 이름을 바꾸고, 지우고, 요일마다 하나씩 배정한다. 이 티켓이 모달과 알림 부품을 처음 만든다. [스펙](../spec.md)의 "시간표와 요일 배정", "화면"과 `DESIGN.md`, [디자인 계약 시안](../assets/10-design-contract.html)을 따른다.

Blocked by: 31

Status: ready-for-agent

- [ ] 시간표 화면을 열면 오늘 요일이 선택되어 있다. 요일 동그라미 일곱 개가 배정된 시간표의 색으로 보이고, 마우스를 올리면 시간표 이름이 뜬다.
- [ ] 시간표 선택 입력기를 누르면 화면 가운데에 모달이 뜬다. 시간표를 고르면 선택한 요일의 배정이 바뀌고 즉시 저장된다. "없음"과 "새 시간표"는 항상 맨 아래에 보이고, 목록은 다섯 줄 반 높이에서 스크롤된다.
- [ ] "새 시간표"는 이름 "새 시간표"로 만들어지고 색 여덟이 만든 순서대로 배정된다. 시간표를 지워도 남은 시간표의 색은 바뀌지 않는다.
- [ ] "편집"을 누를 때만 줄마다 이름 바꾸기와 지우기가 나타나고 "완료"로 돌아간다. 빈 이름으로는 바꿀 수 없다.
- [ ] 요일에 배정되지 않은 시간표는 바로 지워지고 알림의 "되돌리기"로 복구된다. 배정된 시간표는 영향받는 요일을 보여 주는 확인 모달을 거치고, 지우면 그 요일은 없음이 된다.
- [ ] 모달과 알림이 `DESIGN.md`의 규칙대로다(되돌릴 수 없는 일의 기본 초점은 "취소", Esc로 닫힘, 성공 알림은 4초, 실패와 "되돌리기" 알림은 남음).
- [ ] 저장 실패 알림과 "저장된 시간표를 읽지 못해 새로 시작했어요" 알림이 뜬다.
- [ ] 실제 앱 테스트: 시간표를 만들어 요일에 배정하고 앱을 다시 띄우면 남아 있다. 배정 안 된 시간표를 지우고 되돌린다. 배정된 시간표를 지우면 확인 모달이 뜬다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
