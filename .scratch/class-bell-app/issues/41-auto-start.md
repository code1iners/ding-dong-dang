# 41: 자동 시작

**What to build:** PC를 켜면 앱이 저절로 떠서 창 없이 트레이 · 메뉴 막대에 머문다. 등록에 실패하면 설정 화면에서 알 수 있다. [스펙](../spec.md)의 "상주"와 `DESIGN.md`의 "설정" 규칙을 따른다. 배경은 [상주와 신뢰성 정책 결정](07-background-reliability-policy.md)과 [서명 없는 최소 Electron 앱으로 상주 동작 실측](12-unsigned-app-measurement.md)이다.

Blocked by: 40

Status: ready-for-agent

- [ ] 처음 실행할 때 자동 시작을 등록한다. 설정 화면의 "컴퓨터를 켜면 자동 시작" 스위치를 끄면 등록을 지우고, 켜면 다시 등록한다.
- [ ] 설정 화면은 OS에 물은 실제 등록 상태로 실패를 판단하고, 실패면 그 줄에 "등록하지 못했어요"와 "자동 시작 등록 방법" 링크를 보여 준다.
- [ ] 자동 시작으로 떴을 때는 창을 열지 않는다. 직접 실행했을 때만 창을 연다. 구분하는 방법을 OS별로 확인해 티켓에 적는다. macOS에서 구분할 수 없으면 멈추고 사용자에게 확인한다.
- [ ] `--data-dir`로 띄운 테스트 실행은 OS의 자동 시작 등록을 건드리지 않는다.
- [ ] 에이전트가 이 Mac에서 패키징한 앱으로 등록과 해제가 OS에 반영되는지 확인하고, 끝난 뒤 등록을 지운다. 로그아웃 뒤 실제로 뜨는지는 확인하지 않는다.
- [ ] 등록 상태에 따른 설정 줄의 세 모습(켬, 끔, 실패)이 테스트로 확인된다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
