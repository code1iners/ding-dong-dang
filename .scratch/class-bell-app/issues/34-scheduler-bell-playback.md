# 34: 스케줄러와 종 재생

**What to build:** 저장 파일의 시간표와 요일 배정대로 앱이 종을 울린다. 창이 없어도 울리고, 수업 구간 동안 PC가 방치로 잠들지 않게 막는다. [스펙](../spec.md)의 "종 판정 규칙", "종 재생", "상주"의 잠자기 막기를 따른다. 숨긴 창에서 소리를 내는 방식의 선례는 `prototypes/bell-probe/`다.

Blocked by: 31, 32, 33

Status: ready-for-agent

- [ ] 스케줄러가 시계, 1초 타이머, 깨어남 신호, 종 재생, 잠자기 막기를 갈아 끼울 수 있는 부품으로 받는다. 메인 프로세스에서 돈다.
- [ ] 가짜 부품을 끼운 테스트가 확인한다: 종 시각에 시작종 · 끝종 재생을 요청한다, 깨어남 신호가 오면 1초를 기다리지 않고 판정한다, 첫 수업 시작에 잠자기 막기를 시작하고 마지막 수업 끝에 해제한다, "수업 중 화면 켜 두기"가 켜져 있으면 화면 꺼짐도 막는다, 울리는 중에 다음 종이 오면 앞의 종을 끊는다, 오늘만 끄기를 켜면 울리던 종을 멈춘다.
- [ ] 종 재생기가 숨긴 창에서 시작종 · 끝종으로 고른 음원을 음원별 음량 × 전체 음량으로 한 번 재생한다. 종 재생, 멈춤, "지금 울리는 중인지"를 메인에 알린다.
- [ ] 저장된 시간표나 요일 배정이 바뀌면 다음 판정부터 새 값을 쓴다.
- [ ] 실제 앱 테스트: 몇 초 뒤에 시작하는 수업 시간이 든 저장 파일을 임시 데이터 폴더에 써 넣고 앱을 띄우면 숨긴 창에서 재생이 시작된다. 앱이 뜨기 직전에 지난 종은 울리지 않는다.
- [ ] 제품 코드에 시각을 속이는 장치가 없다.
- [ ] 설정 화면에 "수업 중 화면 켜 두기" 줄(스위치, 기본 끔)이 있고 바꾸는 즉시 저장된다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
