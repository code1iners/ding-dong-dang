# 앱 아이콘 시안 비교와 확정

Status: resolved
Blocked by: 08, 18

## Question

앱 아이콘과 트레이 · 메뉴 막대 아이콘은 어떤 모습인가? 레퍼런스 조사에서 나온 방향 후보를 단독 HTML 시안으로 만들어 사용자가 보고 하나를 고른다.

- 고른 디자인 방향과 어울리는 후보를 여러 개 그려, 큰 크기와 작은 크기(작업 표시줄, Dock, 트레이)를 함께 보여 준다.
- 밝은 배경과 어두운 배경, Windows와 macOS의 모양 틀에서 각각 어떻게 보이는지 나란히 놓는다.
- 트레이 · 메뉴 막대 아이콘이 꺼진 상태(오늘만 끄기, 전체 끄기)를 구분해 보여 줄지 정한다.
- 확정한 아이콘의 원본을 어떻게 만들지(직접 그린 벡터, AI 생성 등)를 함께 정한다.

## Answer

시안을 보고 사용자가 확정한 내용이다. 시안 원본은 `prototype/design-mockups` 브랜치의 `prototypes/class-bell-design/app-icons.html`에 있다. 얼굴 한가득, 귀 달린 종, 방울 목걸이는 버린 후보다.

앱 아이콘:

- **발바닥 종**이다. 주황(`#F2A33C`) 바탕에 흰 종이 있고, 종 몸통에 주황 발바닥(큰 볼록살 하나와 발가락 넷)이 찍혀 있다. 종 아래에 크림색 추가 보인다. 강아지 얼굴은 넣지 않는다.
- macOS는 정사각형 원본에 시스템이 둥근 사각형 틀을 씌운다. 틀과 그림자를 직접 그려 넣지 않는다.
- Windows는 바탕이 있는 둥근 타일이다. Windows에는 틀이 없으므로 둥근 모서리를 그려 넣은 `.ico`를 macOS 원본과 따로 만든다.

트레이 · 메뉴 막대 아이콘:

- 앱 아이콘과 같은 발바닥 종의 실루엣을 쓴다(종 몸통에 발바닥이 뚫린 모양).
- 꺼진 상태(오늘만 끄기)는 기호 위에 대각선 **빗금**을 그어 구분한다. 상태는 켜짐과 꺼짐 둘뿐이다(전체 끄기는 [디자인 시안 비교와 방향 선택](08-design-mockups.md)에서 빠졌다).
- macOS 메뉴 막대: 검정 + 알파의 템플릿 이미지 두 벌(켜짐, 빗금).
- Windows 트레이: 단색 기호가 아니라 **색 아이콘 하나**를 쓴다. 바탕 없는 노란 종에 갈색 발바닥이다(앱 아이콘의 주황 타일이 아니다). 꺼지면 회색으로 바꾸고 빗금도 함께 긋는다. 밝은 · 어두운 두 벌을 테마에 따라 바꾸지 않는다.

원본:

- 시안처럼 코드로 직접 그린 SVG가 원본이다. AI 생성은 쓰지 않는다. 1024px 앱 아이콘, Windows 타일 `.ico`, 트레이용 PNG · `.ico`를 같은 SVG에서 뽑는다.
- 제안한 방식에 사용자가 다른 의견을 내지 않아 그대로 확정했다.

확인하지 못한 것:

- 시안은 브라우저에서 그린 흉내다. 실제 Dock · 작업 표시줄 · 트레이에서의 모습(특히 Windows 트레이의 16px 색 아이콘과 회색 + 빗금 상태가 구분되는지)은 구현 뒤 `checklists/post-implementation.md`에서 확인한다.
- Windows 트레이의 회색 + 빗금 그림은 시안에 없었다. 사용자가 글로 확정했다.
