# 앱 아이콘 레퍼런스와 규격 조사

Type: research
Status: resolved
Blocked by: 

## Question

강아지 테마 수업 종 앱의 아이콘에는 어떤 레퍼런스가 있고, Windows 11과 macOS에서 아이콘이 지켜야 할 규격은 무엇인가?

- 반려동물 · 강아지 테마 앱과 종 · 알람 · 타이머 앱의 실제 아이콘 사례(이름, 출처 링크, 형태와 색의 특징).
- 사례에서 반복되는 구성 방식(캐릭터 얼굴, 사물 하나, 강아지와 종의 결합 등)과 작은 크기에서 알아보기 쉬운 조건.
- Windows 11과 macOS의 앱 아이콘 규격: 필요한 크기와 파일 형식(`.ico`, `.icns`), macOS의 모양 틀과 여백, Electron 빌드 도구가 요구하는 원본.
- 트레이 · 메뉴 막대 아이콘의 규격: 크기, macOS 템플릿 이미지(단색), 밝은 · 어두운 배경 대응, 꺼진 상태 같은 상태 표시 사례.
- 서로 뚜렷이 다른 아이콘 방향 후보 3~4개를 이름과 특징으로 정리한다(아이콘 시안 티켓의 입력).

## Answer

조사 문서: `research/app-icon-references` 브랜치(커밋 `fe6647f`)의 `docs/research/app-icon-references.md`.

확인 방식: App Store · Mac App Store의 앱 16개 아이콘과 GitHub 저장소 파일을 직접 열어 봤고, 규격은 Apple · Microsoft · Electron · electron-builder 공식 문서로 확인했다. 방향 후보는 조사 에이전트의 종합이다. Microsoft Store 사례는 이미지를 열지 못해 넣지 않았다.

아이콘 방향 후보 4개 (아이콘 시안 티켓의 입력):

- **A. 얼굴 한가득**: 강아지 정면 얼굴이 캔버스를 채우고 종은 작은 소품. 16px에서 잘 보이지만 종 앱이라는 점이 사라진다. 말랑 스티커와 어울린다.
- **B. 귀 달린 종**: 종 몸통에 귀 · 눈 · 코를 붙여 종이 곧 강아지 얼굴. 16px 가독성이 가장 좋고 트레이 기호와 실루엣을 공유한다. 세 화면 방향 모두와 어울린다. 조사 범위에서 강아지와 종을 결합한 선례는 찾지 못했다.
- **C. 방울 목걸이**: 손그림 외곽선의 강아지 반신과 큰 방울. 32px 이하에서는 방울만 남긴 축약판이 따로 필요하다. 포근한 미용실과 어울린다.
- **D. 픽셀 멍종**: 16 · 32 격자 스프라이트. 정수배에서 또렷하지만 Windows 20 · 24px는 따로 찍어야 한다. 픽셀 산책길과 어울린다.

규격의 핵심:

- 앱 아이콘 원본은 1024×1024 정사각형 하나. electron-builder는 `build/icon.svg` 또는 `build/icon.png`로 `.icns` · `.ico`를 자동 생성한다(최소 입력 macOS 512, Windows 256).
- Windows `.ico`에는 16 · 20 · 24 · 32 · 40 · 48 · 64 · 256px를 담으면 Microsoft 최소 요건과 Electron 권장을 모두 충족한다.
- macOS 26 이상은 정사각형 원본에 시스템이 둥근 사각형 마스크를 씌운다. 마스크 · 그림자 · 하이라이트를 직접 그려 넣지 않는다.
- 작은 크기 조건(Apple · Microsoft 지침 일치): 도형 수 최소화, 얇은 선과 글자 금지, 은유는 최대 두 개, 실루엣으로 구분.
- 트레이 · 메뉴 막대 아이콘은 앱 아이콘과 별도의 단색 기호로 따로 그린다.
  - macOS: 검정 + 알파의 템플릿 이미지. 파일 이름이 `…Template.png`(16×16)와 `…Template@2x.png`(32×32)여야 한다.
  - Windows: `.ico` 16 · 20 · 24 · 32px. 자동 반전이 없어 색 아이콘 하나로 버티거나 밝은 · 어두운 두 벌을 테마에 따라 바꾼다.
- 상태 표시 사례: KeepingYouAwake는 채운 형태와 외곽선 형태로, Stretchly는 일시 정지 기호를 겹쳐 구분한다. macOS에서는 색 없이 형태만으로 구분해야 한다.

시안에서 확인할 것:

- 켜짐 · 오늘만 끄기 · 전체 끄기가 16px 단색 기호에서 구분되는지.

확인하지 못한 항목:

- macOS 26 이전 방식 `.icns`의 틀 치수와, 그런 `.icns`가 macOS 26 이상에서 실제로 어떻게 보이는지.
- electron-builder가 자동 생성하는 `.ico`의 크기 구성.
- `nativeTheme.shouldUseDarkColorsForSystemIntegratedUI`가 들어간 최소 Electron 버전.
