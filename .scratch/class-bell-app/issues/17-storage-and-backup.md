# 저장 방식과 백업 결정

Type: grilling
Status: resolved
Blocked by: 

## Question

시간표, 요일 배정, 설정은 어디에 어떤 형태로 저장하고, 백업이나 내보내기가 필요한가?

- 저장 위치와 형식(사용자 데이터 폴더의 파일 하나인지 등), 앱을 지우거나 다시 설치할 때 남는지.
- 저장 파일이 깨졌거나 읽을 수 없을 때의 동작.
- 등록 음원 파일(앱 데이터 폴더에 복사해 보관, [종소리 정책 결정](06-bell-policy.md))을 저장 · 백업 · 내보내기 범위에 어떻게 포함하는지.
- 다른 PC로 옮기거나 PC를 바꿀 때를 위한 내보내기 · 가져오기가 v1에 필요한지.
- 이후 버전에서 저장 형태가 바뀔 때를 대비한 버전 표기가 필요한지.

## Answer

2026-11-17에 사용자와 그릴링으로 정했다.

### 저장 위치와 형식

- OS가 앱마다 주는 사용자 데이터 폴더(Windows `%APPDATA%` 아래, Mac `~/Library/Application Support` 아래)에 JSON 파일 하나로 시간표, 요일 배정, 설정, 음원 목록을 모두 담는다. 종류별로 파일을 나누지 않고 DB도 쓰지 않는다.
- 등록 음원 파일은 같은 폴더의 `sounds/`에 둔다.
- 오늘만 끄기는 켠 날짜와 함께 저장한다. 앱이 다시 시작돼도(재부팅, 앱 내 업데이트 뒤 재실행) 같은 날이면 꺼진 상태를 유지하고, 날짜가 바뀌었으면 무시한다.
- 창 크기와 위치도 기억한다.

### 저장 시점

- 저장 단추는 시간표 편집에만 있다. 설정, 요일 배정, 음량, 음원 등록 · 이름 바꾸기 · 삭제는 바꾸는 즉시 저장한다.
- 저장에 실패하면(디스크 가득 참, 권한 문제) 바꾼 내용은 앱이 켜져 있는 동안 그대로 쓰고, 창에 "저장하지 못했어요"를 알리고, 다음 변경 때 다시 시도한다. 시간표 편집의 저장 단추에서 실패하면 편집 화면을 닫지 않고 그 자리에서 알린다.

### 깨진 파일

- 저장은 임시 파일에 쓴 뒤 바꿔치기한다. 쓰는 도중 전원이 꺼져도 반쯤 쓰인 파일이 남지 않는다.
- 저장할 때마다 직전의 정상 파일을 예비본 하나로 남긴다. 본 파일을 읽을 수 없으면 알리지 않고 예비본으로 시작한다.
- 둘 다 읽을 수 없으면 깨진 파일을 다른 이름으로 치워 두고(지우지 않는다) 빈 상태로 시작하며, 창에 "저장된 시간표를 읽지 못해 새로 시작했어요"를 한 번 알린다.
- 치워 둔 파일은 가장 최근 것 하나만 남긴다.

### 형태 버전

- 파일에 형태 버전 숫자 하나를 넣는다. 새 앱이 옛 형태의 파일을 만나면 시작할 때 자동으로 올려 쓴다.
- 앱이 아는 것보다 높은 버전의 파일(옛 버전을 다시 설치한 경우)은 읽지 않고, 깨진 파일과 같이 치워 두고 빈 상태로 시작하며 알린다.

### 등록 음원 파일이 사라졌을 때

- 앱이 시작할 때 등록 음원 파일이 없거나 재생할 수 없으면 그 음원을 목록에서 뺀다. 시작종 · 끝종으로 쓰이던 자리는 기본 내장 음원으로 돌린다. 알림은 띄우지 않는다.

### 내보내기 · 가져오기

- v1에 넣지 않는다. PC를 바꾸면 시간표를 다시 입력하고 음원을 다시 등록한다.
- README에 "데이터 폴더를 통째로 복사하면 옮겨져요"와 폴더 위치를 적는다.

### 소리만 끄는 설정

- 전용 음소거 설정은 두지 않는다. 소리 없이 강아지 창만 보고 싶으면 전체 음량을 0으로 내린다(전체 음량 슬라이더는 0까지 내려간다).

### 앱을 지울 때

- 기본은 데이터를 남긴다. 다시 설치하면 시간표와 등록 음원이 돌아온다.
- Windows: 제거할 때 "저장한 시간표와 종소리도 지울까요?"를 한 번 묻는다. 기본은 "아니요"다. 앱 내 업데이트가 옛 버전을 걷어 낼 때는 묻지 않고 항상 남긴다. 로그인 시 자동 실행 등록은 어느 쪽을 고르든 제거 때 지운다.
- 두 OS 공통: 설정 화면 맨 아래에 "모든 데이터 지우기"를 둔다. 확인을 받은 뒤 지우고 앱을 종료한다. Mac은 제거 프로그램이 없어 이것이 유일한 경로다.
- 지우는 범위: 저장 파일과 예비본, 치워 둔 깨진 파일, 등록 음원, 내려받아 둔 업데이트 파일, 창 크기 같은 앱 내부 기록, 로그인 시 자동 실행 등록. 사용자가 따로 가진 원본 음원 파일은 건드리지 않는다.

### 검증 (에이전트, 2026-11-17)

- 이 Mac에서 electron-builder 26.18.0, `toolsets.nsis: "1.2.1"`, `oneClick: true`로 `nsis.include`의 `customUnInstall` 매크로에 한국어 `MessageBox`(`/SD IDNO`, `${isUpdated}`일 때 건너뜀)와 데이터 폴더 · 자동 실행 등록 삭제를 넣어 설치 파일이 오류 없이 만들어지는 것을 확인했다. `.nsh` 파일은 UTF-8 BOM으로 저장했다.
- 실제 Windows에서 질문이 뜨고 선택대로 지워지는지는 확인하지 못해 [구현 뒤 점검 목록](../checklists/post-implementation.md)으로 넘겼다.

글로서리는 바꾸지 않았다(새 도메인 용어 없음). ADR도 만들지 않았다(되돌리기 어렵거나 뜻밖인 결정이 없다).
