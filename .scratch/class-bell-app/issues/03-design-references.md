# 강아지 테마 귀여운 디자인 레퍼런스 조사

Type: research
Status: resolved
Blocked by: 

## Question

'강아지와 관련된 귀여운 디자인, 텍스트 최소화, 시각 위주의 깔끔한 화면'에 맞는 레퍼런스는 무엇이고, 거기서 어떤 방향 후보를 뽑을 수 있는가?

- 반려동물 · 강아지 테마 앱과 귀여운 타이머 · 알람 · 시간표 앱의 실제 사례(이름, 출처 링크, 화면 특징).
- 사례에서 반복되는 색, 형태, 캐릭터 사용 방식, 타이포그래피, 텍스트 대신 시각 요소로 시간과 상태를 보여 주는 방법.
- 서로 뚜렷이 다른 방향 후보 2~3개를 이름과 특징으로 정리한다(시안 티켓의 입력).
- 한글 UI에 쓸 수 있는 무료 라이선스 둥근 글꼴 후보.

## Answer

조사 문서: `research/design-references` 브랜치(커밋 `8395072`)의 `docs/research/design-references.md`.

확인 방식: 공식 페이지(App Store, Steam, GitHub, 공식 사이트)와 그 스크린샷으로 확인한 사례 8개. 앱을 설치해 실행하지는 않았다. 팔레트 hex는 측정값이 아닌 제안값이고, 방향 후보는 조사 에이전트의 종합이다.

방향 후보 3개 (시안 티켓의 입력):

- **A. 말랑 스티커** (근거: Focus Dog, Time Timer): 큰 둥근 카드와 알약 버튼, 플랫 벡터 2등신 마스코트. 강아지 얼굴을 감싼 원판이 줄어들고 교시는 발바닥 도장 개수로 표시. 위험: 흔한 모양이라 구별이 약하다.
- **B. 포근한 미용실** (근거: Focus Friend, Forest): 크림 · 복숭아 바탕에 손그림 외곽선. 벽시계 원판과 장면 전환(수업 = 미용대 위, 쉬는 시간 = 바닥에서 놀기). 위험: 그림 작업량이 가장 많다.
- **C. 픽셀 산책길** (근거: Sill Dogs, VS Code Pets): 픽셀 스프라이트와 수평 띠 화면. 화면 아래 가로 길이 하루 시간표이고 강아지 위치가 현재 시각. 위험: '깔끔하게' 요구와 취향이 갈릴 수 있다.

그 밖의 사실:

- 바닥을 돌아다니는 연출이 시간 표시와 한 장치로 묶이는 것은 C뿐이다.
- 확인한 타이머 앱은 모두 그림과 함께 숫자 시각을 남겨 두었다. 세 후보 모두 남은 시간 숫자 하나는 남기는 것으로 잡았다.
- 시간표 편집 화면은 Time Timer의 목록(항목별 색 + 미니 원판)이 참고가 된다.
- 앱 내장이 가능하다고 확인한 한글 글꼴: Jua, Dongle, Gaegu, Gamja Flower, Hi Melody(모두 SIL OFL 1.1), 나눔스퀘어라운드(네이버 글꼴 라이선스, 굵기 4종).

미확인: 사례 앱의 실제 실행 화면과 애니메이션, VS Code Pets 그림 에셋의 라이선스, 글꼴의 실제 한글 렌더링, 메이플스토리 서체의 세부 조건, 후보 C용 한글 픽셀 글꼴. 한국어 UI의 귀여운 타이머 사례는 찾지 못했다.
