# 디자인 계약 확정

Type: grilling
Status: open
Blocked by: 08, 09, 23

## Question

고른 시안 방향을 스펙이 참조할 디자인 계약(`DESIGN.md`)으로 어떻게 고정하는가?

- 색, 글꼴, 형태, 여백, 아이콘 · 일러스트 사용 규칙.
- 텍스트 최소화 원칙의 구체 기준(무엇은 반드시 글자로 쓰는지).
- 강아지 캐릭터의 모습과 연출이 화면 디자인과 어울리는 규칙.
- 트레이/메뉴 막대 아이콘과 앱 아이콘의 방향.

## Comments

2026-11-16, [상주와 신뢰성 정책 결정](07-background-reliability-policy.md)에서 넘어온 것:

- 창을 처음 닫아 트레이 · 메뉴 막대로 숨길 때 한 번 뜨는 "딩동댕은 계속 켜져 있어요" 안내의 모양.
- 설정 화면에서 macOS 자동 실행 등록 실패를 표시하는 방식.

2026-11-17, [배포와 설치 방식 결정](11-distribution-decision.md)에서 넘어온 것:

- 설정 화면의 "버전" 줄, 설정 단추의 주황 점, 업데이트 확인 모달, 업데이트 뒤 알림의 모양은 [업데이트 화면 시안](../assets/11-update-flow.html)으로 정했다. 디자인 계약에 모달과 알림의 규칙으로 옮긴다.
