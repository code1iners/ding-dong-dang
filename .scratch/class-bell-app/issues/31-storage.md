# 31: 저장소

**What to build:** 시간표, 요일 배정, 설정, 음원 목록이 데이터 폴더의 JSON 파일 하나에 남고, 전원이 꺼지거나 파일이 깨져도 앱이 뜬다. 창 크기와 위치도 기억한다. [스펙](../spec.md)의 "저장"을 따른다.

Blocked by: 30

Status: ready-for-agent

- [ ] 저장소 모듈이 데이터 폴더 경로 하나를 받아 스펙의 파일 모양을 읽고 쓴다. 쓰기는 임시 파일에 쓴 뒤 바꿔치기하고, 쓸 때마다 직전의 정상 파일을 예비본으로 남긴다.
- [ ] 임시 폴더의 실제 파일로 다음이 테스트된다: 쓰고 다시 읽기, 본 파일이 깨지면 예비본으로 시작, 둘 다 깨지면 치워 두고 빈 상태로 시작, 치워 둔 파일은 하나만 남음, 낮은 형태 버전 올리기, 높은 형태 버전은 깨진 파일처럼 처리, 쓸 수 없는 폴더에서 실패를 돌려줌.
- [ ] 처음 실행한 빈 상태의 기본값이 스펙과 같다(시작종 · 끝종은 웨스트민스터 짝, 음량 100, 돌아다니는 강아지 켬, 키 96, 자동 시작 켬, 닫으면 숨기기 켬, 화면 켜 두기 끔).
- [ ] 저장에 실패하면 바꾼 내용을 메모리에 두고 계속 쓰며 다음 변경 때 다시 시도한다. 실패했다는 사실이 화면 쪽으로 전달된다(알림 모양은 [시간표 만들기와 요일 배정](35-timetable-create-assign.md)에서 만든다).
- [ ] 둘 다 읽지 못해 새로 시작했다는 사실이 화면 쪽으로 한 번 전달된다.
- [ ] 창을 옮기거나 크기를 바꾼 뒤 다시 띄우면 그 자리와 크기로 열린다. 저장된 위치가 연결된 모니터 밖이면 기본 위치로 연다(실제 앱 테스트).
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
