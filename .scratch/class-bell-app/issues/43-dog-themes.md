# 43: 나머지 강아지 테마와 테마 고르기

**What to build:** 강아지 테마 일곱 개가 모두 움직이고, 설정 화면에서 그림을 눌러 바꾼다. [스펙](../spec.md)의 "강아지 테마"를 따른다. 부위 표는 [강아지 테마 SVG의 부위 구성 확인](23-dog-theme-svg-parts.md)이다.

Blocked by: 42

Status: resolved

- [x] 나머지 다섯 테마(코드로 그린 주황 강아지, Fluent Emoji 얼굴, Noto Emoji 얼굴, 갈색 · 흰색 강아지, The Creative Idea 강아지)가 여섯 동작을 갖는다. 코드로 그린 강아지는 걷고 나머지 넷은 통통 튄다.
- [x] Fluent Emoji와 Noto Emoji 테마는 고리 안에서 얼굴 그림을, 화면 바닥용으로 같은 세트의 전신 그림을 갖는다. 전신 그림은 고치지 않는다. 갈색 · 흰색 강아지의 풀밭은 뺀다.
- [x] 테마마다 신남과 졸림이 평소와 구분된다(꼬리가 없는 테마는 귀와 혀로, 혀가 없는 테마는 꼬리와 귀로, 갈색 · 흰색 강아지의 졸림은 고개 숙임과 느린 숨쉬기로).
- [x] 설정 화면 맨 위에 테마 일곱 개가 이름 없이 그림만 나란히 있고 평소 동작으로 움직인다. 누르면 바로 적용되고 저장된다. 화면의 색, 모양, 글꼴, 아이콘은 바뀌지 않는다.
- [x] 옮긴 그림마다 출처와 라이선스가 적혀 있다(Fluent Emoji MIT, Noto Emoji Apache-2.0, 나머지는 Unsplash License).
- [x] 테스트: 일곱 테마의 부위 표가 그림의 요소와 맞고 동작마다 그려진다. 에이전트가 테마 × 동작 캡처를 눈으로 보고 결과를 티켓에 적는다.
- [x] 실제 앱 테스트: 설정에서 테마를 바꾸면 고리 안 강아지가 바뀌고 앱을 다시 띄워도 유지된다.
- [x] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
