# 44: 돌아다니는 강아지

**What to build:** 주 모니터의 화면 바닥에 강아지가 나와 수업 시간에는 돌아다니고 그 밖의 시간에는 제자리에서 존다. 누르면 하트가 나오고, 종이 울릴 때 누르면 종이 멈춘다. 꺼 두어도 종이 울리는 동안에는 나타난다. [스펙](../spec.md)의 "돌아다니는 강아지"를 따른다. 행동은 [강아지 연출의 범위와 동작 결정](09-roaming-dog-behavior.md), 창을 만드는 법은 [돌아다니는 강아지 창을 Mac에서 검증하기](28-roaming-dog-window-verification.md)가 원본이고 `prototypes/dog-window-probe/`가 선례다. 끌기와 크기는 [강아지 끌기, 낙하산, 크기](45-dog-drag-parachute-size.md)에서 한다.

Blocked by: 40, 42

Status: ready-for-agent

- [ ] 강아지 행동이 순수 상태 기계다. 구간, 종 울림, 누르기, 경과 시간, 난수를 값으로 받아 동작과 위치를 낸다. 테스트: 수업 중에는 걷기 5~10초와 멈춰 쉬기 10~20초를 되풀이한다, 그 밖의 구간과 오늘만 끄기 중에는 제자리에서 졸림이다, 종이 울리는 동안 신남이다, 동작 줄이기 때는 이동하지 않는다, 주 모니터의 좌우 끝을 넘지 않는다.
- [ ] 강아지 창이 검증 티켓의 "창 만드는 법" 구성으로 뜬다(작은 투명 창, 포커스 안 받음, 클릭 통과를 33ms마다 커서 위치로 바꿈). 앱을 시작하면 주 모니터 바닥의 무작위 위치에 나타나고, 앱 창이 숨어 있어도 보인다.
- [ ] 그리는 횟수가 타이머로 정해진다. 평소 · 졸림은 초당 4번, 그 밖의 동작은 초당 24번이다. 화면 잠금과 잠자기 신호에 그리기를 멈추고 풀리면 다시 그린다.
- [ ] 걷는 테마는 걷고 나머지는 통통 튄다. Fluent Emoji와 Noto Emoji 테마는 전신 그림으로 나온다.
- [ ] 누르면 2초쯤 신남이 되고 하트 8개가 나온다. 종이 울리는 동안 누르면 종이 멈춘다.
- [ ] 설정 화면에 "돌아다니는 강아지" 스위치(기본 켬)가 있고 트레이 · 메뉴 막대 메뉴의 "돌아다니는 강아지" 항목과 같은 값이다. 끄면 강아지 창이 숨는다.
- [ ] 꺼진 상태에서 종이 울리면 그동안만 주 모니터 바닥의 가운데에 신남 상태로 나타났다 사라진다. 화면에 강아지가 둘 뜨지 않는다.
- [ ] 실제 앱 테스트: 앱을 띄우면 강아지 창이 있다, 종이 울리면 강아지 창이 신남 상태가 된다, 설정을 끈 상태에서 종이 울리면 강아지 창이 나타났다 재생이 끝나면 사라진다, 강아지 창이 뜰 때 앱 창이 포커스를 잃지 않는다.
- [ ] 에이전트가 이 Mac에서 수업 중 행동을 10분 돌려 앱 전체의 평균 CPU를 재고 티켓에 적는다. 한 코어의 5%를 넘으면 멈추고 사용자에게 확인한다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
