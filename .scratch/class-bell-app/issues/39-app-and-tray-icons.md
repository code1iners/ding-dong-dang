# 39: 앱 아이콘과 트레이 아이콘

**What to build:** 발바닥 종 아이콘이 코드로 그린 SVG 원본 하나에서 앱 아이콘과 트레이 · 메뉴 막대 아이콘으로 뽑힌다. 원본 결정은 [앱 아이콘 시안 비교와 확정](19-app-icon-selection.md), 규격은 [앱 아이콘 레퍼런스와 규격 조사](18-app-icon-references.md)다. 시안은 `prototype/design-mockups` 브랜치의 `app-icons.html`에 있다.

Blocked by: 30

Status: ready-for-agent

- [ ] SVG 원본에서 다음이 스크립트로 뽑힌다: 1024px 정사각형 앱 아이콘(틀과 그림자 없음), Windows 둥근 타일 `.ico`(16 · 20 · 24 · 32 · 40 · 48 · 64 · 256), macOS 메뉴 막대 템플릿 이미지 두 벌(켜짐, 빗금, 각 1배 · 2배, 검정 + 알파), Windows 트레이 색 아이콘 두 벌(켜짐은 노란 종에 갈색 발바닥, 꺼짐은 회색에 빗금).
- [ ] 테스트가 산출물의 존재, 크기, `.ico` 안의 크기 구성, 템플릿 이미지에 색이 없는 것을 확인한다.
- [ ] 에이전트가 산출물을 16px과 큰 크기에서 눈으로 보고 켜짐과 빗금이 구분되는지 확인해 결과를 티켓에 적는다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
