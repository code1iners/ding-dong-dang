# 33: 내장 종소리 만들기

**What to build:** 내장 음원 열두 개(여섯 짝의 시작 · 끝)가 WAV 파일로 저장소에 있다. [스펙](../spec.md)의 "음원"을 따른다. 악보와 음색의 원본 값은 [종소리 청취 시안](../assets/16-bell-sounds.html)의 `SCORES`와 `TIMBRES.chime`이고, 짝과 길이는 [종소리 청취 시안과 음원 확정](16-bell-sound-selection.md)의 표다.

Blocked by: 30

Status: ready-for-agent

- [ ] 스크립트 하나가 원본 값으로 파형을 계산해 열두 개의 WAV를 만든다. 브라우저 없이 돈다. 만든 파일은 저장소에 넣는다.
- [ ] 음원마다 고정된 id와 화면 이름(짝 이름 "웨스트민스터", "딩동댕동", "띠링", "다섯 음", "아르페지오", "화음"에 "시작" 또는 "끝")이 있다.
- [ ] 테스트가 확인한다: 열두 파일이 모두 있다, 길이가 표와 0.1초 안에서 맞는다, 어느 파일도 최대값이 1을 넘지 않는다, 파일끼리의 크기(RMS)가 정한 범위 안에 있다.
- [ ] 스크립트를 다시 돌려도 저장소의 파일과 같은 결과가 나온다.
- [ ] 뒤에 더한 넷(띠링, 다섯 음, 아르페지오, 화음)은 에이전트가 파형을 확인한 적이 없다. 이 티켓에서 처음 확인하고, 화음에서 찌그러짐이 나오면 음을 바꾸지 않고 크기만 줄여 맞춘다. 그것으로 안 되면 멈추고 사용자에게 확인한다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
