# 38: 종 화면

**What to build:** 종 화면에서 전체 음량을 조절하고, 종소리를 미리 듣고, 시작종과 끝종을 고르고, 자기 파일을 종소리로 등록한다. [스펙](../spec.md)의 "음원", "종 재생"과 `DESIGN.md`의 "종" 화면 규칙을 따른다.

Blocked by: 34

Status: ready-for-agent

- [ ] 위에 전체 음량 슬라이더(0~100)와 "종소리 등록"이 있다. 목록의 줄마다 미리 듣기, 이름, 음량, 시작종 · 끝종 선택 동그라미가 있다. 내장 음원 열두 개가 처음부터 있다.
- [ ] 미리 듣기는 누르면 재생, 다시 누르면 멈춤이고 실제 종과 같은 크기다. 다른 줄을 누르면 앞의 것이 끊기고, 미리 듣는 중에 종 시각이 오면 미리 듣기가 끊기고 종이 울린다.
- [ ] 등록: mp3 · wav · m4a · ogg를 고르면 데이터 폴더의 `sounds/`로 복사되고 확장자를 뺀 파일 이름으로 목록에 나온다. 60초를 넘거나 재생할 수 없는 파일은 이유와 함께 거절된다.
- [ ] 등록한 종소리에만 이름 바꾸기와 지우기가 있다. 지우면 바로 빠지고 알림의 "되돌리기"로 복구된다. 시작종 · 끝종으로 쓰이던 것을 지우면 그 자리는 웨스트민스터 짝으로 돌아가고, 되돌리면 선택도 돌아온다. 복사해 둔 파일은 되돌릴 수 없게 된 뒤에 지워진다.
- [ ] 모든 변경이 즉시 저장된다.
- [ ] 앱이 시작할 때 등록 음원의 파일이 없거나 재생할 수 없으면 알리지 않고 목록에서 빼며, 쓰이던 자리는 기본 음원으로 돌린다.
- [ ] 실제 앱 테스트: 종소리를 등록해 시작종으로 고른 뒤 지우면 기본 음원으로 돌아가고 "되돌리기"로 복구된다. 61초짜리 파일이 거절된다. `sounds/`의 파일을 지우고 앱을 다시 띄우면 그 줄이 없다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
