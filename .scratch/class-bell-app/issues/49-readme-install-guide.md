- 루트 `README.md`를 한국어로 새로 썼다. 순서: 소개 영상 자리, 한 줄 소개, 내려받기(고정 주소 두 개), Windows 설치(SmartScreen 본편 + "차단 화면이 뜨면 (Smart App Control)" 절: 확인 · 끄기 · 영향), Mac 설치("그래도 열기"), 업데이트, 그 밖의 안내(자동 시작 수동 등록 방법, 데이터 폴더, 덮개 · 음량, 여러 날 쉴 때), 맨 아래 개발자용.
