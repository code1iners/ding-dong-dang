# 49: README 설치 안내

**What to build:** 공개 저장소의 한국어 README를 읽고 학원 직원이 설치 전에 경고를 넘기는 방법을 알 수 있다. [스펙](../spec.md)의 "배포와 설치"의 README 항목과 [배포와 설치 방식 결정](11-distribution-decision.md)의 "설치 안내"를 따른다. 경고의 사실 관계는 [서명 없는 Electron 앱의 설치 경험과 빌드 방법 조사](02-unsigned-distribution.md)와 [서명 없는 빌드 산출물의 설치 실측](14-unsigned-build-install-measurement.md)이다.

Blocked by: 46, 47

Status: ready-for-agent

- [ ] 순서: 소개 영상 자리, 한 줄 소개, 내려받기 링크(Windows · Mac, 고정 주소), Windows 설치 절차, Mac 설치 절차, 업데이트 방법, 그 밖의 안내, 맨 아래에 개발자용 내용.
- [ ] Windows 절차: 설치 파일 실행과 SmartScreen 통과가 본편이다. 그 뒤에 "차단 화면이 뜨면"으로 시작하는 Smart App Control 절이 있고 상태 확인 방법, 끄는 절차, 끄면 생기는 영향을 모두 적는다.
- [ ] Mac 절차: 열기 시도 뒤 시스템 설정 > 개인정보 보호 및 보안의 "그래도 열기".
- [ ] 그 밖의 안내: 자동 시작 수동 등록 방법(설정 화면의 링크가 이 절을 가리킨다), 데이터 폴더 위치와 "데이터 폴더를 통째로 복사하면 옮겨져요", "덮개를 닫으면 종이 울리지 않아요", "종이 안 들리면 PC 음량과 스피커 전원을 확인하세요", 여러 날 쉴 때는 자동 시작을 끄고 종료하는 방법.
- [ ] 영상 셋의 자리는 비워 두고 표시해 둔다. 실제 경고 화면을 보지 못하고 쓴 문구는 그렇다고 표시해, 수동 통합 테스트 뒤에 고칠 수 있게 한다.
- [ ] 말투는 "~해요"이고 용어는 화면의 말("종소리", "종료", "지우기", "자동 시작")과 같다.
- [ ] README의 링크가 모두 맞는 주소 형식이고, 앱의 "자동 시작 등록 방법" 링크가 README의 그 절로 간다.
