# 40: 트레이 상주

**What to build:** 창을 닫아도 앱이 트레이 · 메뉴 막대에 남아 종을 울린다. 메뉴에서 창을 열고, 종을 멈추고, 오늘 종을 끄고, 앱을 종료한다. [스펙](../spec.md)의 "상주"와 `DESIGN.md`의 "처음 닫을 때", "트레이 · 메뉴 막대 메뉴"를 따른다.

Blocked by: 34, 39

Status: ready-for-agent

- [ ] 닫기 버튼이 창을 숨기고 앱은 살아 있다. 처음 숨길 때 한 번 "딩동댕은 계속 켜져 있어요" 모달이 뜨고 "창 닫기"를 누르면 숨는다(강아지 그림의 자리는 [강아지 그리기와 고리 안 강아지](42-dog-rendering-ring-dog.md)에서 채운다).
- [ ] 설정 화면에 "닫으면 숨기기" 줄(스위치, 기본 켬)이 있다. 끄면 닫기 버튼이 앱을 종료한다.
- [ ] 트레이 · 메뉴 막대 메뉴가 `DESIGN.md`의 순서대로다: "딩동댕 열기", "종 멈추기"(울릴 때만), "오늘 종"(체크), "딩동댕 종료". "돌아다니는 강아지" 항목은 [돌아다니는 강아지](44-roaming-dog.md)에서 더한다.
- [ ] "오늘 종"은 현황의 스위치와 같은 값이고, 꺼지면 아이콘이 빗금 상태로 바뀐다. Windows에서 아이콘을 왼쪽 클릭하면 창이 열린다.
- [ ] "딩동댕 종료"와 macOS의 Cmd+Q는 확인 없이 종료한다.
- [ ] 한 번에 하나만 실행된다. 다시 실행하면 기존 앱의 창이 열린다.
- [ ] macOS에서 창이 닫힌 동안 Dock 아이콘이 숨는다.
- [ ] 실제 앱 테스트: 창을 닫으면 숨고 앱이 살아 있다, 처음 닫을 때만 모달이 뜬다, 두 번째 실행이 기존 창을 연다, 창이 숨은 상태에서도 종 재생이 시작된다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
