# 강아지 연출의 범위와 동작 결정

Type: grilling
Status: open
Blocked by: 04

## Question

돌아다니는 강아지는 어디에서, 어떻게 행동하는가?

- '화면 바닥'이 앱 창 안의 바닥인지, 데스크톱 화면 전체의 바닥인지.
- 강아지의 동작 목록(걷기, 앉기, 자기 등)과 수업 시간 · 쉬는 시간 · 종이 울리는 순간에 따라 행동이 달라지는지.
- 클릭이나 마우스에 반응하는지.
- 켜고 끄는 설정의 기본값, 앱 창이 숨겨졌을 때의 동작.

이미 정해진 전제([종소리 정책 결정](06-bell-policy.md)): 종이 울리는 동안에는 강아지 표시 설정과 무관하게 화면 아래쪽에 항상 위에 뜨는 작은 강아지 창이 뜨고, 누르면 종이 멈춘다. 즉 앱 창 밖 화면에 강아지를 띄우는 창이 적어도 하나는 필요하다. 평소 돌아다니는 강아지가 이미 화면에 있을 때 종이 울리면 그 강아지가 이 역할을 맡는지도 여기서 정한다.
