# 42: 강아지 그리기와 고리 안 강아지

**What to build:** 현황의 고리 안에서 강아지가 상태에 따라 움직인다. 누르면 신나 하며 하트가 나오고, 종이 울리는 동안 누르면 종이 멈춘다. 그림 한 장에 부위별 움직임을 붙이는 그리기 모듈을 테마 둘로 세운다. [스펙](../spec.md)의 "강아지 테마"와 `DESIGN.md`의 "강아지", "움직임"을 따른다. 부위 표는 [강아지 테마 SVG의 부위 구성 확인](23-dog-theme-svg-parts.md), 움직임 값의 출발점은 [돌아다니는 강아지 시안](../assets/09-roaming-dog.html)의 `MOVES`다.

Blocked by: 37

Status: ready-for-agent

- [ ] 그리기 모듈이 테마(그림, "부위 이름 → 요소 번호, 관절 위치" 표)와 동작을 받아 그린다. 화면 기준의 관절과 변환을 요소의 좌표계로 옮기는 식 하나로 움직이고, 테마마다 따로 맞춘 코드가 없다.
- [ ] 기본 테마(앉아 있는 주황 강아지)와 뻐드렁니 강아지가 여섯 동작(평소, 신남, 졸림, 이동, 끌려가기, 낙하)을 갖는다. 기본 테마는 통통 튀고 뻐드렁니 강아지는 다리를 번갈아 움직여 걷는다. 뻐드렁니 강아지의 그림자는 뺀다.
- [ ] 쓰는 그림을 `~/.claude-mukkebi/mockups/ding-dong-dang/assets/`에서 저장소로 옮기고 출처와 라이선스를 적은 파일을 함께 둔다. 기본 테마의 표는 `prototype/design-mockups` 브랜치의 `dog-idle.html`에서 가져온다.
- [ ] 고리 안 강아지가 `DESIGN.md`의 "현황" 표대로 평소 또는 졸림이고, 종이 울리는 동안에는 신남이다.
- [ ] 고리 안 강아지를 누르면 2초쯤 신남이 되고 하트 8개가 떠올라 1초 안에 사라진다. 종이 울리는 동안 누르면 종이 멈춘다.
- [ ] 처음 닫을 때 모달에 강아지가 나온다.
- [ ] OS의 동작 줄이기가 켜져 있으면 창 안의 강아지는 멈춘 그림이다.
- [ ] 테스트: 두 테마의 부위 표가 그림의 요소와 맞는다(없는 요소 번호가 없다), 동작마다 그림이 깨지지 않고 그려진다. 에이전트가 동작별 캡처를 눈으로 보고 빈 곳이나 어긋남이 없는지 확인해 티켓에 적는다.
- [ ] 실제 앱 테스트: 종이 울리는 동안 고리 안 강아지를 누르면 재생이 멈춘다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
