# 37: 현황 화면

**What to build:** 창을 열면 지금 교시와 다음 종까지 남은 시간이 고리, 숫자, 발바닥 도장으로 보이고, "오늘 종" 스위치로 오늘 남은 종을 끈다. [스펙](../spec.md)의 "현황 계산", "화면"과 `DESIGN.md`의 "현황" 표를 따른다.

Blocked by: 34

Status: ready-for-agent

- [ ] 창을 열면 현황 화면이다. `DESIGN.md`의 여섯 상태가 고리, 글, 발바닥 도장으로 그려진다. 고리 안 강아지의 자리는 비워 둔다([강아지 그리기와 고리 안 강아지](42-dog-rendering-ring-dog.md)에서 채운다).
- [ ] 고리가 지금 구간의 남은 시간만큼 줄어들고 남은 시간이 초마다 바뀐다. 한 시간이 넘으면 "시:분:초"로 쓴다. 숫자는 자리마다 같은 폭의 칸에 들어가 흔들리지 않는다.
- [ ] 발바닥 도장이 지난 교시, 지금 교시, 남은 교시를 모양으로 구분한다.
- [ ] "오늘 종" 스위치를 끄면 끈 날짜가 저장되고 울리던 종이 멈춘다. 다시 켜면 풀린다. 꺼진 동안에도 현황은 시간표대로 나온다.
- [ ] 시간표가 하나도 없으면 "시간표를 만들어 주세요"와 "시간표 만들기" 단추가 나오고, 누르면 시간표 화면으로 간다.
- [ ] 실제 앱 테스트: 오늘 요일과 지금 시각에 맞춰 만든 저장 파일로 여섯 상태가 각각 맞게 나온다. 스위치를 끄고 앱을 다시 띄우면 꺼진 상태가 유지되고, 끈 날짜가 어제인 파일로 띄우면 켜져 있다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
