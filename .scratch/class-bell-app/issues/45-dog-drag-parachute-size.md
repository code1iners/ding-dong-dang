# 45: 강아지 끌기, 낙하산, 크기

**What to build:** 돌아다니는 강아지를 끌어 옮길 수 있고, 놓으면 낙하산을 펴고 내려온다. 설정의 슬라이더로 크기를 바꾼다. [스펙](../spec.md)의 "돌아다니는 강아지"와 [강아지 연출의 범위와 동작 결정](09-roaming-dog-behavior.md)의 "누르기와 끌기"를 따른다. 끌기 방식은 [돌아다니는 강아지 창을 Mac에서 검증하기](28-roaming-dog-window-verification.md)의 구성이다.

Blocked by: 44

Status: ready-for-agent

- [x] 주 모니터 안 어디로든 끌 수 있고 끄는 동안 커서를 따라온다. 끄는 동안의 위치는 메인이 커서 위치로 계산한다. 주 모니터 밖으로 나가지 않는다.
- [x] 놓으면 주황 · 크림 줄무늬 낙하산(코드로 그림)이 펼쳐져 수직으로 내려온다. 화면 맨 위에서 바닥까지 7~8초쯤이다. 내려오는 중에 다시 잡을 수 있다.
- [x] 상태 기계 테스트: 끌려가는 중과 내려오는 중에는 구간이 바뀌거나 종이 울려도 그 동작을 끝내고 착지한 뒤 새 상태가 된다, 내려오는 강아지를 눌러도 종이 멈춘다, 종이 울리는 중에 끌기 시작하면 종이 멈춘다, 설정이 꺼진 상태에서 종 때문에 나타난 강아지는 끌 수 없다, 동작 줄이기 때는 낙하산 없이 바로 바닥에 놓인다.
- [x] 설정 화면의 크기 슬라이더(키 64~160, 기본 96)를 움직이는 즉시 강아지, 하트, 낙하산이 함께 커지고 저장된다. 창 크기는 검증 티켓의 식을 따른다. 고리 안 강아지의 크기는 바뀌지 않는다.

- [x] 키 64와 160에서 하트와 낙하산이 창 안에 다 들어오는 것을 캡처로 확인한다.
- [x] 타입 검사, 린트, 전체 자동 테스트가 통과한다.

## Comments

2026-11-18, 구현 기록(에이전트):

- 상태 기계 `src/shared/roaming-dog.ts`에 누르기 · 끌기 · 낙하를 더했다: `holdDog`(누름), `moveHeldDog`(커서가 5px 넘게 움직이면 끌기 시작, 그 뒤 누른 자리를 커서 밑에 둔 채 따라옴), `releaseDog`(뗌: 끌던 중이면 낙하, 아니면 누른 것). 강아지는 이제 발끝 `y`를 갖고, 끄는 범위는 좌우가 걷는 범위(끝에서 반 너비 + 8px), 위는 머리가 주 모니터 위 끝에 닿을 때까지, 아래는 바닥이다. 낙하 빠르기는 맨 위(발끝 = 위 끝 + 키)에서 바닥까지 7.5초가 되도록 화면 높이로 정한다(키 96, 이 Mac에서 초당 약 117px).
- 메인(`src/main/roaming-dog.ts`)은 누르고 있는 동안 초당 24번 `screen.getCursorScreenPoint()`로 끄는 자리를 정하고 창을 옮긴다(28번 구성). 하트는 이제 메인이 "누른 것"으로 칠 때만 강아지 창에 신호(`dog:hearts`)를 보내 띄운다. 끌고 놓은 것은 하트가 없다.
- 강아지 창: 시안 09번의 낙하산 그림(주황 · 크림 줄무늬)을 코드로 붙였다. 너비 1.5H, 줄이 모이는 끝이 발끝에서 0.55H 위다. 낙하가 시작되면 펴지고 착지하면 접힌다. 끄는 동안은 옮겨 가는 반대쪽으로 최대 20° 기울고, 내려올 때는 ±5° 흔들린다(시안 값). 동작 줄이기 때는 기울이지 않는다.
- 설정: "돌아다니는 강아지" 줄에 시안 10번처럼 "작게 · 슬라이더 · 크게 · 스위치"를 두었다. 슬라이더는 키 64~160, 명령 `set-dog-height`(정수 64~160만 받음)로 움직이는 즉시 저장한다. 기존 `Slider`에 범위와 읽을 값 글을 받게 했다(화면 읽기는 "강아지 크기, 키 96").
- 하트: 강아지 창에서는 떠오르는 거리(46px)와 가운데 맞춤도 키에 비례하게 했다(`--heart-rise`). 고리 안 강아지는 예전 값 그대로다.
- 판단: 바닥에서 4px 안쪽에서 놓으면 낙하산 없이 그대로 내려놓는다. 0.04초짜리 낙하산이 깜빡이지 않게 하려는 작은 시각 규칙이다.
- 판단(리뷰 반영): 누르고 있는 동안은 강아지가 걷거나 내려오지 않는다. 내려오는 강아지를 누른 채 있으면 커서 밑에서 빠져나가 하트 · 종 멈춤이 안 되던 문제를 막는다. 떼면 낙하를 잇는다.
- 판단: 끄는 중에 창이 숨으면(설정 끔 등) 그 자리에서 놓은 것으로 하고, 다시 보일 때 낙하를 끝내고 착지한다.
- 기존 시험 고침: 얼굴 테마 그림 요소 수 시험이 낙하산 svg까지 세지 않게 `.roaming-dog__flip svg`로 좁혔다. 종 · 포커스 시험은 강아지 창이 뜨기 전에 다른 앱이 맨 앞을 가져가면(이 Mac에서 Chrome · Slack이 맨 앞을 가져간 것을 `lsappinfo`로 확인) 포커스 판정을 경고로 남기고 넘어가게 했다. 강아지 창이 뜬 뒤의 포커스 잃음은 그대로 실패다.
- "지금 화면" 단추의 선택 테두리(사용자 결정)는 이미 있어 건드리지 않았다.
