# 45: 강아지 끌기, 낙하산, 크기

**What to build:** 돌아다니는 강아지를 끌어 옮길 수 있고, 놓으면 낙하산을 펴고 내려온다. 설정의 슬라이더로 크기를 바꾼다. [스펙](../spec.md)의 "돌아다니는 강아지"와 [강아지 연출의 범위와 동작 결정](09-roaming-dog-behavior.md)의 "누르기와 끌기"를 따른다. 끌기 방식은 [돌아다니는 강아지 창을 Mac에서 검증하기](28-roaming-dog-window-verification.md)의 구성이다.

Blocked by: 44

Status: ready-for-agent

- [ ] 주 모니터 안 어디로든 끌 수 있고 끄는 동안 커서를 따라온다. 끄는 동안의 위치는 메인이 커서 위치로 계산한다. 주 모니터 밖으로 나가지 않는다.
- [ ] 놓으면 주황 · 크림 줄무늬 낙하산(코드로 그림)이 펼쳐져 수직으로 내려온다. 화면 맨 위에서 바닥까지 7~8초쯤이다. 내려오는 중에 다시 잡을 수 있다.
- [ ] 상태 기계 테스트: 끌려가는 중과 내려오는 중에는 구간이 바뀌거나 종이 울려도 그 동작을 끝내고 착지한 뒤 새 상태가 된다, 내려오는 강아지를 눌러도 종이 멈춘다, 종이 울리는 중에 끌기 시작하면 종이 멈춘다, 설정이 꺼진 상태에서 종 때문에 나타난 강아지는 끌 수 없다, 동작 줄이기 때는 낙하산 없이 바로 바닥에 놓인다.
- [ ] 설정 화면의 크기 슬라이더(키 64~160, 기본 96)를 움직이는 즉시 강아지, 하트, 낙하산이 함께 커지고 저장된다. 창 크기는 검증 티켓의 식을 따른다. 고리 안 강아지의 크기는 바뀌지 않는다.
- [ ] 에이전트가 이 Mac에서 실제 마우스 입력을 합성해(선례는 `prototypes/dog-window-probe/`의 `input-test.sh`) 끌기, 화면 끝에서 멈춤, 낙하와 착지를 확인하고 결과를 티켓에 적는다.
- [ ] 키 64와 160에서 하트와 낙하산이 창 안에 다 들어오는 것을 캡처로 확인한다.
- [ ] 타입 검사, 린트, 전체 자동 테스트가 통과한다.
