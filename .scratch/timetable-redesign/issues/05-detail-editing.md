# 05: 상세 편집: 시간대 · 요일 · 수업 시간 저장

**What to build:** 학원 강사가 상세에서 시간대를 고르고 더하고 지우며, 요일을 한 화면에서 켜고 끄고, 시계판을 보며 수업 시간을 고친 뒤 "저장" 한 번으로 반영하거나 "되돌리기"로 한 번에 취소한다. 저장하지 않고 나가려 하면 확인 창이 뜬다. 목록 카드에 시간대 요약이 보인다. [스펙](../spec.md)의 "시간표 화면 — 상세"(왼쪽 카드 2~4번, 오른쪽 카드, 저장 단위)와 "시간표 화면 — 목록"의 시간대 요약을 따른다. 화면은 `DESIGN.md`와 [시안](https://macbook-m5-pro.tail9db1f7.ts.net:8445/ding-dong-dang/timetable-flow.html)의 "2 · 상세 편집"을 따른다.

Blocked by: 04

Status: ready-for-agent

- [ ] 왼쪽 카드 이름 아래에 시간대 탭(이름은 요일 요약: "월~금", "토", "요일 없음")과 "+ 다른 시간대"가 있다. "+ 다른 시간대"는 어느 시간대에도 들지 않은 요일이 있을 때만 나온다.
- [ ] 고른 시간대의 요일 동그라미가 있고, 같은 시간표의 다른 시간대가 쓰는 요일은 나오지 않는다. 시간대가 둘 이상이면 이 줄 끝에 "이 시간대 지우기"가 있고, 하나면 없다.
- [ ] 고른 시간대의 시계판이 남는 높이를 다 쓰고, 가운데 강아지는 `DESIGN.md`대로다. 기존 `Dial`을 쓴다.
- [ ] 오른쪽 카드 위에 "월~금 수업 시간"처럼 고른 시간대를 밝히고, 교시 줄(넘치면 줄만 스크롤)과 "+ 수업 시간"이 있다. 새 수업 시간 기본값과 잘못된 시각 표시는 지금과 같다. 기존 `TimeField`를 쓴다.
- [ ] 맨 아래 오른쪽에 "되돌리기" · "저장"이 늘 같은 자리에 있다. 바꾼 것이 없으면 둘 다 꺼지고, 잘못된 시각이 있으면 "저장"만 잠긴다.
- [ ] 요일 켜고 끄기, 시간대 더하기 · 지우기, 수업 시간 추가 · 수정 · 삭제는 초안에 쌓이고, "저장"이 시간대 저장 한 번으로 반영하며 "저장했어요"를 알린다. "되돌리기"는 초안을 버린다.
- [ ] 초안이 있는 채 "← 시간표 목록"이나 다른 화면으로 가려 하면 "계속 편집 / 저장 안 함 / 저장" 확인 창이 "'이름' 시간표의 요일이나 수업 시간을 바꿨어요." 문구로 뜬다.
- [ ] 만든 직후 초점이 첫 요일 동그라미에 놓인다(04의 임시 자리를 바꾼다).
- [ ] 목록 카드에 시간대별 요약이 두 줄까지("월~금 6교시 · 09:00~15:50"), 셋째부터 "외 N개"로 보인다.
- [ ] e2e(`period-editing` 다시 쓰기): 요일 켜기, 시간대 더하기, 수업 시간 더하기 후 저장 → 앱을 다시 띄워도 남고, 그 요일 · 시각에 종이 울린다. 되돌리기로 초안이 사라진다. 저장 안 하고 목록으로 가면 확인 창이 뜨고 세 단추가 각각 맞게 동작한다. 한 시간대에서 켠 요일이 다른 시간대 요일 줄에 없다.
- [ ] 접근성 e2e: 키보드만으로 시간대 탭 고르기, 요일 켜기, 수업 시간 더하고 고치기, 저장까지 끝낼 수 있고, 확인 창의 Esc와 초점 돌아오기가 맞다.
- [ ] 창 920 × 580과 1000에서 상세의 두 카드가 잘리거나 겹치지 않고, 교시가 많아도 "되돌리기" · "저장"이 보이는 것을 에이전트가 실제 앱에서 확인한다.
- [ ] 마지막 변경 뒤 `npm run check`가 통과한다.
