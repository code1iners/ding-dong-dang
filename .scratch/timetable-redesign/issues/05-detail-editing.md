# 05: 상세 편집: 시간대 · 요일 · 수업 시간 저장

**What to build:** 학원 강사가 상세에서 시간대를 고르고 더하고 지우며, 요일을 한 화면에서 켜고 끄고, 시계판을 보며 수업 시간을 고친 뒤 "저장" 한 번으로 반영하거나 "되돌리기"로 한 번에 취소한다. 저장하지 않고 나가려 하면 확인 창이 뜬다. 목록 카드에 시간대 요약이 보인다. [스펙](../spec.md)의 "시간표 화면 — 상세"(왼쪽 카드 2~4번, 오른쪽 카드, 저장 단위)와 "시간표 화면 — 목록"의 시간대 요약을 따른다. 화면은 `DESIGN.md`와 [시안](https://macbook-m5-pro.tail9db1f7.ts.net:8445/ding-dong-dang/timetable-flow.html)의 "2 · 상세 편집"을 따른다.

## Comments

- 2026-11-19 구현(에이전트):
  - 상세는 `TimetableDetail`이 맡는다. 초안(시간대 목록)이 상세 안에 있고, "저장"은 `set-slots` 한 번이다. 시간대 조작은 순수 함수 `src/shared/slot-edit.ts`(보일 요일, 요일 켜고 끄기, 시간대 더하기·지우기, 저장 모양, 비교)에, 요일·시간대 요약은 `weekdays.ts`의 `daysSummary` · `slotSummary`에 있다.
  - 바꾼 결과가 저장된 값과 같아지면(켰다 다시 끄기 등) 초안을 비워 두 단추가 다시 꺼진다. 저장에 실패하면 초안이 남아 같은 "저장"으로 다시 저장한다.
  - 떠나기 확인은 03에서 걷어 낸 앱 쪽 가드(`registerGuard` · `set-editing-dirty` · 창 닫기)를 되살려 "← 시간표 목록", 왼쪽 세로 줄, 창 닫기에 건다.
  - 리뷰에서 찾은 버그를 고쳤다: 시각을 치고 Enter 없이 목록 밖(예: "저장")을 누르면 정렬이 옛 초안으로 덮어 친 값이 빠졌다. e2e로 재현한 뒤 고쳤다.
- 시안 · 스펙과 다른 점과 스펙에 없던 작은 결정(사용자 확인 항목):
  - `DESIGN.md` 시간표 상세 설명은 "고른 시간대의 요일 동그라미 일곱"이고, 스펙 · 이 티켓은 "다른 시간대가 쓰는 요일은 나오지 않는다"다. 티켓대로 구현했고 `DESIGN.md` 문구는 고치지 않았다. 문구를 맞출지 확인이 필요하다.
  - 목록 카드의 시간대 요약을 시안처럼 작은 시계판 옆이 아니라 아래 카드 폭 전체에 두었다. 창 920의 카드 폭(내용 224px)에서는 옆에 두면 "월~금 6교시 · 09:00~15:50"이 여러 줄로 쪼개져 "두 줄까지"가 지켜지지 않는다.
  - 고른 시간대 탭은 시안의 짙은 면 + 흰 글자 대신 DESIGN.md 선택 표시(글자 색 3px 테두리를 3px 띄움)로 그렸다. DESIGN.md는 "흰 글자는 빨강 위에만"이다. 켠 요일의 체크 표시는 시안대로 글자 색 원 위의 흰 체크 아이콘이다(글자가 아니라 아이콘).
  - "되돌리기" · "저장"은 `disabled` 대신 `aria-disabled`로 잠근다. 누른 뒤 꺼져도 키보드 초점이 그 자리에 남고, 잠겨도 Tab이 닿는다.
  - 요약 표기: 사흘 이상 이어진 요일은 "월~금", 그보다 짧거나 떨어진 요일은 "토 · 일", 일곱 요일은 "매일"(시안), 수업 시간 없는 시간대는 "토 수업 시간 없음"(시안).
  - 잘못된 시각이 든 시간대 탭에 느낌표가 붙고, 고른 시간대 밖에만 오류가 있으면 "저장" 위에 "토 시간대에 잘못된 시각이 있어요. 고친 뒤 저장해 주세요."를 쓴다(DESIGN.md "잠긴 단추는 이유를 옆에 글로"). 확인 창도 시간대가 둘 이상이면 "토 1교시: …"처럼 시간대를 밝힌다.
  - 수업 시간이 없으면 시안대로 "아직 수업 시간이 없어요"를 보인다.
  - 고른 시간대에 보일 요일이 하나도 없으면 상세에 들어올 때 초점은 ✎에 둔다(만든 직후에는 늘 첫 요일 동그라미).
  - 확인 창 제목은 스펙의 "지금의 확인 창"대로 "바꾼 내용을 저장할까요?"를 유지했다(DESIGN.md "제목은 행동과 대상"과는 차이, 대상은 본문 "'이름' 시간표의 …"에 있다).
