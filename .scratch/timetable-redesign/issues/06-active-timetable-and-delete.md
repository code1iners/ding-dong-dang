# 06: 쓰는 시간표 바꾸기와 지우기

**What to build:** 시간표가 둘 이상이면 학원 강사가 목록에서 어느 시간표로 종이 울리는지 보고, 다른 시간표의 상세에서 "이 시간표 쓰기"로 바꾼다. 시간표 지우기는 항상 확인 창을 거치고, 쓰는 시간표를 지우면 종이 멈춘다고 미리 알려 준다. [스펙](../spec.md)의 "시간표 화면 — 목록"(쓰는 중 표시), "시간표 화면 — 상세"(위 줄 오른쪽), "지우기"를 따른다.

Blocked by: 04

Status: ready-for-agent

- [ ] 시간표가 둘 이상일 때만 쓰는 시간표 카드에 "🔔 쓰는 중" 표시와 굵은 테두리가 있다. 표시가 있어도 없어도 카드들의 요일 줄 위치가 같다.
- [ ] 상세 위 줄 오른쪽: 시간표가 둘 이상일 때만 쓰는 시간표면 "🔔 쓰는 중" 표시, 아니면 "🔔 이 시간표 쓰기" 단추가 나온다. 단추는 즉시 저장하고 "이제 '이름' 시간표로 종이 울려요"를 알린다.
- [ ] 위 줄 맨 오른쪽에 "🗑 시간표 지우기"(빨간 글자의 작은 버튼)가 있다.
- [ ] 지우기는 항상 확인 창을 거친다. 단추는 "취소" · "시간표 지우기"(빨강)이고 초점은 "취소"에 놓인다. 쓰는 시간표이거나 하나뿐인 시간표면 "지금 종이 울리는 시간표예요. 지우면 다른 시간표를 쓰기 전까지 종이 울리지 않아요.", 그 밖은 "지운 시간표는 되돌릴 수 없어요."다.
- [ ] 지우면 목록으로 돌아가고 "'이름' 시간표를 지웠어요"를 알리며 되돌리기는 없다. 쓰는 시간표를 지우면 다른 시간표로 넘기지 않는다.
- [ ] 상세에 저장 안 한 초안이 있을 때 지우기 · 쓰는 시간표 바꾸기가 초안과 섞이지 않는다(05가 먼저 끝났으면 확인, 아니면 Comments에 05 이후 확인 필요로 적는다).
- [ ] 등록 음원 지우기(바로 지우고 되돌리기)는 바뀌지 않는다.
- [ ] e2e: 두 번째 시간표를 만들면 쓰는 중 표시가 생기고, "이 시간표 쓰기"를 누르면 표시가 옮겨 가며 종이 새 시간표를 따르고 현황 이름이 바뀐다. 지우기의 두 문구, "취소"로 남음, 쓰는 시간표를 지우면 종이 없고 현황이 "시간표 없음"이 됨, 하나 남으면 쓰는 중 표시가 사라짐.
- [ ] 접근성 e2e: 키보드만으로 "이 시간표 쓰기"와 지우기 확인 창(Esc, 초점 돌아오기)을 쓸 수 있다.
- [ ] 창 920 × 580과 1000에서 위 줄이 긴 이름과 함께 잘리거나 겹치지 않는 것을 에이전트가 실제 앱에서 확인한다.
- [ ] 마지막 변경 뒤 `npm run check`가 통과한다.
