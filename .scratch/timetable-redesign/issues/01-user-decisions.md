# 01: 사용자 결정 기록

**What to build:** [스펙](../spec.md)의 Further Notes "이 스펙에서 새로 정한 것" 네 가지를 사용자에게 확인받아, 이후 티켓이 사용자 개입 없이 진행된다.

Blocked by: None (can start immediately)

Status: resolved

- [x] 저장 형태를 버전 2로 올린다. 버전 1에서 올릴 때 시간표만 비우고 다른 설정은 남긴다.
- [x] 시간대는 한 개 이상이다. 마지막 시간대는 지울 수 없다("이 시간대 지우기"는 둘 이상일 때만 나온다).
- [x] 목록 카드의 작은 시계판은 첫 시간대를 그린다.
- [x] 시간대 탭 이름은 요일 요약이고, 따로 이름을 붙이지 않는다.
- [x] 테스트를 거는 자리(순수 함수 단위 테스트 · e2e · 에이전트의 실제 환경 확인)와 티켓 나누기를 사용자가 받아들였다.

## Comments

- 2026-11-19 대화에서 사용자가 스펙 보고와 티켓 나누기를 "ok"로 받아들였다. 남은 사용자 결정은 없다. 구현 중 스펙과 다른 사실이나 CPU 5% 초과가 나오면 그때 멈추고 확인받는다.
