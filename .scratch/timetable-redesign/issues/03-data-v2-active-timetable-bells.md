# 03: 쓰는 시간표의 시간대로 종이 울린다(저장 형태 버전 2)

**What to build:** 저장 파일이 버전 2가 되고, 종은 쓰는 시간표에서 그 날짜의 요일이 든 시간대의 수업 시간으로 울린다. 현황 화면에 쓰는 시간표 이름이 보인다. 시간표 화면은 예전 요일 배정 화면 대신 보기만 하는 카드 목록과 빈 상태를 보여 준다(만들기는 04, 상세는 04 · 05). [스펙](../spec.md)의 "데이터", "순수 함수", "시간표 검증", "종 판정과 현황", "시간표 화면 — 목록"과 Testing Decisions를 따른다.

Blocked by: 02

Status: resolved

- [x] 읽기 검증이 한 시간표 안에서 같은 요일이 두 시간대에 있거나 `activeTimetable`이 없는 id인 파일을 깨진 파일로 본다.
- [x] 시간표 조작 순수 함수: 만들기(이름 앞뒤 공백 제거, 빈 이름 거절, 처음 모양은 요일 · 수업 시간 없는 시간대 하나, 첫 시간표는 쓰는 시간표, 색 규칙 그대로), 이름 바꾸기, 시간대 저장(같은 요일 중복 거절, 수업 시간 시작순 정렬), 쓰는 시간표 정하기(있는 id만), 지우기(쓰는 시간표를 지우면 `null`). `restoreTimetable`, `assignWeekday`, `daysUsing`은 없다.
- [x] 시간표 검증이 v1 규칙을 시간대마다 적용하고 다른 시간대끼리는 보지 않는다. 요일 없는 시간대 · 수업 시간 없는 시간대 · 요일 없는 시간표는 통과한다.

- [x] 종 판정 단위 테스트: v1 시나리오 표의 모든 줄을 새 모양으로 옮기고(요일 배정은 "평일반" 한 시간표의 시간대로), 쓰는 시간표가 아닌 시간표는 울리지 않음 · 쓰는 시간표가 없으면 종 없음 · 그 요일이 든 시간대가 없으면 수업 없는 날 · 자정을 걸치면 날짜마다 시간대를 다시 찾음을 더한다.
- [x] 저장 형태 단위 테스트: 버전 1 올리기, 깨진 두 경우.
- [x] 현황 화면이 쓰는 시간표 이름을 보여 주고, 쓰는 시간표가 없으면 지금의 "시간표 없음" 상태를 보여 준다. 문구 자리는 `DESIGN.md`(02에서 고친 것)를 따른다.

- [x] 02의 e2e 도우미가 버전 2 데이터를 만든다. 예전 흐름만 확인하던 `timetable` · `period-editing` e2e의 항목은 지우고, 04 · 05에서 새 흐름으로 다시 쓴다고 이 티켓 Comments에 적는다.

### 2026-11-19 구현 메모(03)

**정한 이름** (04~06이 그대로 씀)
- 저장 형태: `Timetable.slots: TimetableSlot[]`(`{ days: Weekday[]; periods }`), `Data.activeTimetable: string | null`. `activeTimetableOf(...)`는 `src/shared/data.ts`.
- 순수 함수(`src/shared/timetable-ops.ts`): `createTimetable(data, id, name)`, `renameTimetable`, `setSlots(data, id, slots)`, `setActiveTimetable(data, id)`, `deleteTimetable(data, id)`(`Data`를 돌려줌), `daysOverlap(slots)`.
- 검증: `validateSlots(slots)` → `SlotError`(`PeriodError` + `slot` 번호).
- 종 판정 입력: `BellSchedule = { timetables, activeTimetable, bellsOffDate }`. 그날의 수업 시간은 `periodsOfDay` 한 곳(옛 `timetableOn`)이 정한다.
