# 04: 시간표 만들기

**What to build:** 학원 강사가 "새 시간표" 카드나 빈 상태의 "시간표 만들기"를 누르면 이름을 받는 창이 뜨고, 만들면 그 시간표의 상세로 들어간다. 첫 시간표는 아무것도 하지 않아도 쓰는 시간표가 된다. 상세의 뼈대(위 줄의 "← 시간표 목록", 왼쪽 카드의 색 점 · 이름 · ✎ 바꾸기)가 생긴다. [스펙](../spec.md)의 "시간표 화면 — 목록", "시간표 화면 — 만들기", "시간표 화면 — 상세"의 위 줄과 왼쪽 카드 1번을 따른다. 화면은 `DESIGN.md`와 [시안](https://macbook-m5-pro.tail9db1f7.ts.net:8445/ding-dong-dang/timetable-flow.html)을 따르고, 스펙과 `DESIGN.md`가 다르면 멈추고 확인한다.

Blocked by: 03

Status: ready-for-agent

- [ ] 목록 맨 끝 칸이 점선 "+ 새 시간표" 카드이고, 빈 상태에 "시간표 만들기" 단추가 있다.
- [ ] 이름을 받는 창: 제목 "새 시간표", × 닫기, 이름 입력(자리표시 "예: 평일반"), "취소" · "만들기". 이름이 비면(공백만 포함) "만들기"가 잠긴다. Enter는 만들기, Esc는 닫기이고, 닫으면 초점이 누른 단추로 돌아간다. 기존 `Modal`을 쓴다.
- [ ] 만들면 "'이름' 시간표를 만들었어요" 알림이 뜨고 그 시간표의 상세로 들어가며 초점은 첫 요일 동그라미(05 전에는 상세의 첫 조작 요소)에 놓인다.
- [ ] 첫 시간표는 쓰는 시간표로 저장되고, 시간표가 하나뿐이면 목록 · 상세 어디에도 "쓰는 중" 표시가 없다.
- [ ] 목록 카드를 누르면 그 시간표의 상세로 들어간다. 카드는 단추 하나이고 화면 읽기 이름에 전체 이름이 있다.
- [ ] 상세 위 줄(카드 밖) 왼쪽에 "← 시간표 목록"이 있고 누르면 목록으로 돌아간다.
- [ ] 왼쪽 카드 맨 위에 색 점 · 이름(두 줄까지, 단어 단위 줄바꿈) · ✎가 있다. ✎를 누르면 그 자리에서 입력으로 바뀌고 ✓ · ×가 나온다. ✓는 즉시 저장하고 빈 이름은 받지 않으며, ×와 Esc는 취소한다.
- [ ] e2e(`timetable` 다시 쓰기): 빈 상태에서 만들기 → 상세에 들어감 → 앱을 다시 띄워도 시간표가 있고 쓰는 시간표다(저장 파일 확인). 이름 창을 ×와 Esc로 닫으면 아무것도 생기지 않는다. 이름 바꾸기가 남는다.
- [ ] 접근성 e2e: 키보드만으로 "새 시간표" → 이름 입력 → Enter → 상세 → "← 시간표 목록"까지 갈 수 있고, 창의 Tab 순서와 Esc 닫기, 초점 돌아오기가 맞다.
- [ ] 창 920 × 580과 1000에서 이름 창 · 상세 뼈대가 잘리거나 겹치지 않는 것을 에이전트가 실제 앱에서 확인한다.
- [ ] 마지막 변경 뒤 `npm run check`가 통과한다.
