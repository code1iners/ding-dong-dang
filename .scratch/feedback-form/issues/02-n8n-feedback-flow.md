# 02: n8n 제보 흐름: 딩동댕 폼 → Data Table → Gmail 알림

**What to build:** 누구나 브라우저로 `/form/ding-dong-dang`을 열어 제보를 보낼 수 있고, 보낸 제보는 Data Table에 "새 제보"로 쌓이며 개발자 Gmail로 알림이 온다. [스펙](../spec.md)의 Implementation Decisions "n8n 워크플로"와 [ADR 0002](../../../docs/adr/0002-feedback-via-n8n-form.md)를 따른다. 워크플로는 n8n MCP로 만든다(SDK 참조 → 노드 타입 확인 → 검증 → 생성 순서).

- [x] 워크플로 하나에 딩동댕 Form Trigger(경로 `ding-dong-dang`)가 있고, 그 뒤에서 제품을 폼의 상수("딩동댕")로 붙인 다음 공용 저장 · 알림 단계로 이어진다. 다른 제품의 Form Trigger를 더하면 같은 단계로 합류할 수 있는 모양이다.

- [x] 워크플로가 활성이고, 운영 폼 주소에 `curl`로 GET하면 200이다.

- [x] 테스트로 생긴 표의 줄은 지우거나 "닫힘"으로 둔다.
