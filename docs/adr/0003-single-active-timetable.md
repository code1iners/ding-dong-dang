# 종은 쓰는 시간표 하나만 따르고, 시간표가 요일별 시간대를 가진다

딩동댕 v1은 요일마다 시간표를 하나씩 배정했다. 월~금에 같은 시간표를 쓰려면 요일 동그라미마다 시간표 선택 창을 열어 다섯 번 골라야 했고, 만들 때 이름도 정하지 못했다. 그런데 사용자는 보통 시간표를 하나만 쓴다. 여러 개를 두는 것은 방학 특강이나 단축 수업 같은 예외에 대비하기 위해서다. 구조가 "요일마다 다른 시간표"를 기본으로 가정해서 흔한 경우가 불편해졌다.

그래서 요일 배정을 버린다. 시간표가 자기 요일과 수업 시간을 **시간대**로 묶어 가지고(예: 월~금 6교시, 토 2교시), 종은 **쓰는 시간표** 하나만 따라 울린다. 시간표가 하나뿐이면 그 시간표가 쓰는 시간표이고 화면에는 이 개념이 드러나지 않는다. 쓰는 시간표를 지우면 다른 시간표로 넘기지 않고 종이 멈춘다. 저장 형태는 버전 2로 올리며, 아직 배포 전이라 버전 1의 시간표와 요일 배정은 옮기지 않는다.

## Considered Options

- **요일마다 시간표 배정을 유지하고 여러 요일을 한 번에 배정하는 창만 만든다**: 데이터를 바꾸지 않지만 "보통 하나만 쓴다"는 흔한 경우가 여전히 요일 배정이라는 개념을 거치고, 요일마다 다른 시각은 시간표를 나눠야 한다.
- **시간표 여러 개를 동시에 울린다**: 요일이 겹칠 때 어느 종을 따를지 정해야 하고, 예외 대비라는 쓰임에 비해 규칙이 복잡하다. 고르지 않았다.

## Consequences

- 한 시간표 안에서 같은 요일이 두 시간대에 들어갈 수 없다. 저장 파일을 읽을 때 이를 어기거나 `activeTimetable`이 목록에 없는 id이면 깨진 파일로 본다.
- 방학이나 단축 수업 때는 사용자가 상세 화면에서 쓰는 시간표를 직접 바꿔야 한다. 날짜나 요일에 따른 자동 전환은 하지 않는다.
- 버전 1 파일의 시간표는 올릴 때 비워진다. 음원, 설정, 창 위치는 남는다.
